# 2F.107 / 4.240.0 本地笔记库统计工作台

接受基线master53e216ae／4.239.0，PR12已完整验收合并；当前分支feature/local-library-statistics-2f107。本模块落实原路线第10项统计面板，不延伸云同步或旧离线报告的小控件。

## 完整用户路径

设置 → 标签与分类 → 打开笔记库统计。读取一次完整本机快照，展示普通笔记、可检索字符、未分类、置顶、文件夹/模板/回收站数量和标签覆盖；展开最近30天UTC日期分布。按标题/未分类/置顶/无可计数字符/无法统计筛选，在同一快照内排序与50条分页，通过原保存保护打开笔记。明确确认后导出JSON，默认只含汇总和日期分布；明确勾选才包含当前查询词、筛选笔记标题和ID，不含正文或磁盘路径。

## 指标定义与边界

普通笔记排除文件夹、模板和回收站；未保存草稿不计入。字符使用既有搜索解析器，按NFC后的Unicode码点排除空白；代码、公式、链接文字和图片说明沿用搜索规则。它不是分词字数，也不是图片/附件大小；content_bytes是已保存正文文本的UTF8字节数，不是数据库磁盘占用。无法解析的正文单列、不给它记零字数或当作空笔记。无可计数字符不代表笔记无附件或可安全删除。

30天按UTC日历显示每篇笔记创建日/当前最后修改日各一次，不是编辑次数、每日新增字数或完整活动历史。列表显示直属文件夹名称，不冒充完整路径。快照有生成时间及内容/元数据/标签摘要，发生本页可观察的资料变更后禁用旧快照导出/导航；其它进程变化仍须重新统计，未声称实时监测所有写入。

GET /api/library-statistics，8秒服务端截止、10秒客户端等待。SQLite同一只读事务先检查20000条文件、普通正文总64MiB/单篇16MiB、元数据2MiB边界，标签及关系沿用500/50000完整读取限制。逐条解析，正文不回传；异常、取消、超限、悬空标签关联拒绝整个结果。无schema迁移、无业务写入。

## 异常闭环

取消/关闭中止本次读取并拒绝迟到结果；失败没有部分统计，重新统计可重试。导出前说明隐私范围，取消不下载；下载失败保留快照，成功只称已发起下载，不冒称文件已落盘。变化撤销导出确认；旧成功文案在下一操作前清除。固定反馈与操作栏不随表单滚动，最小窗口可用；焦点循环、IME及Ctrl+S不穿透到正文，原保存决定显示在统计窗口之上。
