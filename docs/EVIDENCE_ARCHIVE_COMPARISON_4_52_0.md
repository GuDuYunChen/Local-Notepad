# 4.52.0 — 核对存档对比与变化清单

功能基线：`cf2662f499631547a4f9f665e8aa6cb8024bb644`（远程已完成 4.51.0）。
分支：`feature/ui-redesign-v1`。不改 master、正文、数据库、存档格式、恢复规则或当前核对状态，不新增依赖。

## 使用

项目 → 结构 → 实体智能分析 → 正文证据回看 → 本地核对存档 → 对比两份核对存档。
选择“基准 A”和“对照 B”，点击“开始对比”。候选覆盖当前存档查看范围的全部存档，不受存档管理器每页 5 份限制；仅可选择同一项目、同一实体的两份有效快照。切换查看范围或项目后，旧选择失效时不会继续展示其历史内容。

对比按章节 ID 关联，不按同名标题或章序猜测身份。列表先沿 B 的顺序，再附上仅 A 中存在的章节，提供左右两侧标题、序号、人工状态和备注。

- 区分范围新增、范围移出、共同章节有变化及未变化，四类构成完整章节并集。
- 共同章节另统计新增／取消待修改标记、仍待修改、备注、状态、标题、序号与相对次序变化。不同维度可重叠，不应相加作为章节总数。
- 范围移出不算问题解决；取消待修改只表示人工标记被取消，不代表正文问题已修复。历史已核对不代表当前正文已审核。
- 筛选条件不同、B 时间早于 A 或两份时间相同时明确提示。方向始终为用户选择的 A → B，不按导入顺序或时间自行改序。
- 支持变化类型与章节名／ID／两侧备注搜索，每页 8 章；搜索归一化 Unicode 与大小写，原始备注不被改写。
- “导出完整对比”生成 Markdown，包含两份存档的全部章节并集及两侧备注，不受界面筛选或分页限制，不附带正文节选。
- 比较、导出使用现有存档读取与未变化检查；收到本地列表刷新或跨窗口存储事件后，失效对比停用。即使未收到事件，导出时也重新检查两份存档，拒绝导出旧结果。

本功能完全只读，不自动保存、删除或恢复存档，不开始核对、不接受关系建议。清理应用用户数据仍可能丢失本地存档；JSON 是存档备份，Markdown 是供阅读的历史对比，不用于恢复。

## 浏览器验证及限制

实际尝试 Chromium 访问本地测试页面时，管理员策略返回 `ERR_BLOCKED_BY_ADMINISTRATOR`，因此真实浏览器重启持久化及原生跨页 storage 事件测试未完成；没有通过禁用策略绕过限制。

离线挂载实际存档管理器和对比组件，使用合成测试项目及 localStorage 替身（不连接 Go 后端）：验证 19 章 A 与 19 章 B 的 20 章并集实际下载，含移出范围的末页备注；导出时读取保护；不自动开始核对。1440px 深浅主题、640px 深色和 390px 浅色视口无页面或存档区域横向溢出。核查截图后调整了新区域的标签对齐、选择框宽度和说明文字对比度。最终检查未捕获页面运行时异常。

这不是完整 App／真实浏览器持久化／Windows 实机端到端验收。真实 Windows 重启、高 DPI、中文输入法和系统保存行为仍需实机检查。正式后端、Windows 安装包及安装／卸载结果以最终提交对应 Actions 为准。
既有 KaTeX、React act、Lexical 上下文、npm 配置与构建包体积告警未在此阶段清除；不宣称零告警。

临时快照工作流和浏览器测试入口不会保留在最终源码树，原正式 CI 不变。
