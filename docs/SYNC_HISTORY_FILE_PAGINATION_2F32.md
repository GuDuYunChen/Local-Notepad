## 新交互

位置：设置 → 同步中心 → 同步总览 → 离线查看历史文件。沿用原来每页25条，在原分页区增加“首页”“末页”和“跳至第…页”。文件上限2000条，对应最多80页，用户不用连续点击79次下一页。

页码只定位当前文件中已经匹配的记录。与文字、对象、处理结果、UTC日期条件取交集后再分页；跳页不会改变全匹配概览、原文件的导出声明或上方本机历史。保留原有页码和本页记录范围，不把当前页数量当作整个匹配集合。

输入页码只是草稿。点击“跳转”或普通Enter才导航；支持十进制与全角数字，允许前后空白。小数、符号、指数、十六进制、零、超出当前页数的值全部拒绝，保留当前页，不静默夹到末页。修改草稿清除本次输入错误；快捷键修饰的Enter、IME组合中的Enter和229键码不被消费，候选确认本身不触发跳页。

新文件或筛选范围变化时，清除旧跳页草稿/错误，页码与当前有效结果一致；即使新旧文件页数相同也不会留下旧错误。普通父组件重渲染和取消文件选择不清草稿。替换文件失败时继续保留旧文件、当前页和草稿，并沿用已有旧文件来源说明。输入框和导航DOM不重挂载，直接跳页不抢走焦点；列表滚回目标页首。

只有一页时首页/末页/前后页均不可执行；没有匹配记录时输入只读，所有导航不可执行，不产生“第1/0页”。清除筛选仍恢复本文件全量，不重新读取文件。
