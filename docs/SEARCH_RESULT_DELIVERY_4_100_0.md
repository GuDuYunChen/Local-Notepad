# 4.100.0 — 检索结果整理与导出

基线：`feature/ui-redesign-v1`，`dec3e562e43ca8ad55730cee406f031a3c0de857`（4.90.1）。保留已经通过验证的 NSIS 模板修复，不更换后端、不修改 master。

## 完整使用流程

全局检索 → 展开“结果清单与导出” → 在右侧预览加入单篇或“加入本页结果” → 跨页继续选择 → 导出所选或全部结果。

- “移除本页选择”只移除当前页；“清空选择”清空整轮选择。左侧显示已选标记，预览选择与导出选择互相独立。
- 选择只保存在窗口内存，不自动保存搜索历史或正文。相同条件和数据版本下关闭／重开保留选择；条件或资料库版本变化后清空并提示。
- Markdown 适合阅读，JSON 为结构化清单。默认只导出标题、目录、笔记 ID、修改时间、置顶状态、命中数量和正文指纹。
- 只有显式勾选才附带命中节选，每篇最多 3 段，仍显示完整命中数。节选可能含私人内容，清单不是正文备份或全部命中导出。
- 每次最多 2,000 篇、8 MiB。超过范围不静默截断；全部结果过多时仍允许导出上限内的所选结果。
- 所选导出只重读选择所在的页，并按检索顺序输出，不按点击顺序。全部导出读取全部分页。

## 数据一致性与交互保护

每个请求都使用相同的目录、关键词、大小写、固定修改时间起点、排序和资料库版本，清除旧的返回锚点。
校验每页结构、准确页号、数量、版本、ID 唯一性、所选项位置及正文指纹；最终再请求一次复验版本。不混合不同版本，不从 UI 缓存直接拼接文件。
中途失败、版本变化、缺失项、重复项、统计矛盾、取消、两分钟截止或大小超限均不返回部分清单。
关闭、改条件、翻页或进入编辑器保存确认时取消正在准备的导出；旧请求即使稍后成功也不能下载文件，取消不清空仍有效的选择。

下载采用既有浏览器 Blob 方式，释放临时 URL；提示“已发起下载”，不是“已验证写入磁盘”。浏览器取消保存或系统下载策略不一定有回执，需要用户核对下载目录。
Markdown 对源文本标点编码，不允许标题或节选成为活动 HTML、链接、标题或代码围栏。JSON 不携带完整正文、导航偏移、编辑器 token 或任意额外字段，不是可导入的常用检索备份格式。

## 非目标和限制

没有批量改写、替换或删除笔记，没有后台持久索引，没有跨重启结果集。检索只覆盖已保存的活动笔记；未保存草稿、模板、回收站、核对存档和外部附件内容不在清单内。
后端仍按每页查询读取当前数据，解析缓存不等于结果快照数据库；超大资料库可能触发截止，应缩小范围。版本复验只说明最后一次读取时一致，不承诺导出之后原资料库不再变化。
没有新增依赖或数据库迁移。既有包体积、React act、KaTeX、Lexical 等非阻断告警未作为本轮解决项。

技术参考：React `useEffect` cleanup（https://react.dev/reference/react/useEffect）；MDN `AbortSignal`（https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal）；MDN `URL.revokeObjectURL`（https://developer.mozilla.org/en-US/docs/Web/API/URL/revokeObjectURL_static）。
