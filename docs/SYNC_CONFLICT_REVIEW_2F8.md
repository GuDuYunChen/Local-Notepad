## 使用方式

同步中心有冲突时，点击「对照版本」「采用远端」或「保留本机」均只展开对照，不发送处理请求。默认对照不预选版本；方向快捷入口仅预选方向，仍须勾选核对声明并点击「确认处理此冲突」。

两列展示本机/远端的笔记、文件夹、标签、标签关联或附件。笔记展示标题、父文件夹 ID、排序、置顶、时间和正文文本投影；附件仅展示名称、字节数及 SHA-256，不下载或执行二进制。差异项直接比较原始正文/格式及结构字段，不把纯文本投影相同误当成内容相同。小窗口改单列，沿用主题变量和可见键盘焦点。

永久删除、回收站状态与缺失版本分别展示。缺失数据不能冒充空白文档；删除状态额外提示其将应用到另一端。切换方向会清除确认勾选。打开时聚焦对照标题，收起时返回原入口。

## 确认边界

- 捕获不可变的冲突 ID、对象 ID、三个版本摘要、已展示记录和同步目标（设备/provider/端点/用户名/store ID）。不包含密码，不写 localStorage，不新增远端日志。
- 状态刷新或目标改变使旧对照失效；保留旧快照并要求「重新对照」，不会静默替换已经阅读的内容或继承旧确认。
- 最终确认重读 settings/status/conflicts，必须找到且只找到一个匹配的 open 冲突，且目标与内容一致才允许一次 POST。读取失败、重复 ID、缺失/已解决、字段改变或目标改变均拒绝发送。
- 预提交读取有 8 秒预算；离开面板会中止读取。即使读取实现忽略 abort，超时或卸载后的迟到响应也不能触发写入。
- 提交单飞；不自动选边、不批量处理、不自动重试写入。已发出的 POST 不因界面关闭而被描述成撤销。服务端原有协调器/锁/基线与两端实时哈希校验仍为最终权威；前端复核不是服务端原子 compare-and-swap，也不新增断电保证。
- 未保存 WebDAV 配置或状态读取失败时，禁止继续确认冲突。

## 预览与数据完整性

正文只作为 React 文本渲染，不执行 HTML、Markdown、脚本或附件。支持纯文本、JSON 字符串及常见 Lexical 文本节点，保留段落/表格单元边界。未知结构显示原始文本；未展示节点明确提示。预览最多 12,000 个 Unicode 码点，原始内容超过 524,288 个 UTF-16 代码单元时不解析整篇树，遍历最多 20,000 节点；任何截断或未显示对象均提示需要核对完整文档。这是有界文本对照，不是完整富文本或逐字差异编辑器；原始内容不被改写。
