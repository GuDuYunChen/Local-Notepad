# 2F.109 / 4.242.0 本地待办任务中心

## 一个完整本地流程
设置 → 标签与分类 → 打开待办任务中心。只读一致SQLite事务汇总已保存普通笔记中的富文本复选清单和支持的Markdown待办，展示未完成、已完成和含待办笔记。按任务/标题查找、状态筛选、排序与50项分页；检查来源当前正文摘要后进入原保存/放弃/取消保护。已有唯一稳定块地址时定位来源块，否则明确显示来源笔记及行号/待办序号，不伪称精确光标定位。

用户在原编辑器勾选并经原保存流程保存，返回中心重读见到新状态。中心不提供第二套checkbox写入，不覆盖草稿、回执或历史；取消原导航保留清单，外部变化使旧快照失效，取消或关闭丢弃迟到结果，失败可明确重试。入口、操作、结果和异常属于同一模块。

导出必须确认：默认汇总不含任务内容、标题、ID或查询词；显式勾选才附当前筛选任务摘要及来源标题/身份。只声明下载已发起，不声明操作系统落盘成功。取消确认不创建文件。

## 范围和边界
富文本只识别明确listType=check下checked为布尔值的listitem，嵌套任务各自计数，父摘要不重复包含子清单。只沿已知文档子节点遍历，不从代码节点/URL/任意元数据编造任务；未知结构显示覆盖缺口。摘要最多1024个Unicode码点，非文本内容及截断明确标注。重复块ID不用于定位。

Markdown识别行首0–3空格的无序/有序复选标记；围栏代码与引用段不计入。更深缩进的候选标记可能是代码或嵌套清单，明确标记覆盖缺口而不假定完成。状态是当前保存的复选值，不是完成时间、提醒或任务历史。模板、回收站和草稿不在汇总范围；覆盖缺口可打开来源复查。

上限：20000条文件元数据、普通正文合计64MiB、单篇16MiB、10000项待办、响应8MiB、元数据2MiB、节点200000/深度128；超限拒绝整份结果，不返回误导性的部分总数。8秒服务上下文、10秒客户端读取预算，不自动重试。来源打开校验当前正文SHA256和标题，仍由原导航保护决定是否选择。
