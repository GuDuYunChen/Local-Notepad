## 查找与筛选

在原“冲突处理记录”面板内新增“筛选已读取记录”。可按当前标题、对象标识或记录标识查找；按笔记/文件夹、标签、标签关联、附件筛选；按当时保留本机、采用远端、已失效、处理方式未核实筛选。三个条件取交集，保留服务器原始顺序。没有新增独立工作区或大范围改动编辑器外观。

查找使用字面子串而非正则，忽略大小写，支持 Unicode 规范等价及全半角形式。输入最多 128 个 Unicode 字符，不截断代理对。只搜索已白名单投影的三个标识字段，不搜索历史正文、凭据、哈希或未知字段；文字仍由 React 转义。

明确显示“当前显示 X 条 / 已读取 Y 条”。Y 不是全库总数，X 不是全库搜索总数。无匹配但仍有未读页时保留“读取更早记录”入口并提示范围；不会自动翻页。手动追加页面后重新应用当前筛选，不丢失输入。重新读取或失败保留旧结果时，仍沿用当前本地条件并保留既有过期结果提示。

“清除本地筛选”只重置本地文字/对象类型/处理结果，不改变原来的服务器记录类型，不发请求、不清除已加载快照。键盘触发清除后焦点回到输入框；末页移除“更早记录”按钮时，即使结果被本地条件全部隐藏，也有可聚焦的结果区域，不把焦点丢到页面。等待期间用户移走焦点则不抢回。

## 读取和隐私边界

首次打开、输入、修改本地筛选和清除本地筛选都不发起网络请求。只有原有的显式读取、服务器记录类型切换或读取更早记录才使用已有 GET 接口，URL 不包含查找文字。不写 localStorage、不保存查找词、不调用同步/恢复/选边或正文写入；卸载后条件自然清空。

“已失效”继续明确不等于“已选边”。当前标题只用于辨认，不冒充当时正文或历史标题。未知处理方式不推断为本机/远端选择。停止读取、超时、过时请求隔离以及原有分页校验保持不变。
