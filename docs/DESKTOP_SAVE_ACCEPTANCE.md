实际操作使用真实Lexical内容编辑区、真实文件树，以及Chromium输入事件。测试覆盖：
- 改章节标题与正文，Ctrl+S实际写入SQLite，不弹出引用预确认。

- 再改标题和正文，等待真实30秒定时自动保存，不替换或加速计时器。

## 首轮驱动校正

第一次原生运行36597432392已通过真实Ctrl+S和数据库核对，但在打开未编辑的第二篇合成笔记后返回时，被未保存对话框挡住。原始截图与报告保留，不能当作本阶段成功。检查发现驱动用手写JSON初始化笔记，缺少当前Lexical段落默认字段及规范序列化次序；真实编辑器加载会规范化它，因此产生一次真实内容表示变更。改为使用同一个已安装Lexical版本的实际序列化器生成初始合成正文，增加parse/export完全相等测试，不修改产品或跳过弹窗。
