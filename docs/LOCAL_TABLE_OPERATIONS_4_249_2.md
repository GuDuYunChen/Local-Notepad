## 实际组件、数据流和可达操作

`App → TextEditor → Editor` 是普通笔记编辑入口。`TextEditor` 持有整份笔记
内容与保存状态；`Editor` 的 Lexical 文档包含 `TableNode → TableRowNode →
TableCellNode → paragraph/text`。`OnChangePlugin` 把内容更新交回原有整份笔记
保存流程；表格没有独立数据源、行 API、分页接口或第二条持久化路径。

| 入口或模块 | 实际职责 |
| --- | --- |
| `ToolbarPlugin / TableMenu` | 原有网格选择插表；首工作表 Excel 插入；菜单预览与关闭 |
| `blockRegistry / SlashMenu / CommandPalette` | 复用已有内容块插入；命令面板进入表格多选 |
| 原生 `TablePlugin / HistoryPlugin` | 单元格文字编辑、原生选择、节点规范化与撤销重做 |
| `TableActionMenuPlugin` | 当前单元格、行、列的可达菜单操作 |
| `TableSelectionPlugin` | 多选、Ctrl/Cmd 追加、复制粘贴、批量样式、清空、合并拆分 |
| `tableModel` | 同一逻辑网格、稳定节点键、跨度、行列移动及宽度同步 |
| `TableColumnResizePlugin / TableReorderPlugin` | 列宽预览与提交、适应内容、真实行列拖放 |
| `TablePresentationPlugin` | 从已保存状态派生冻结和逻辑列的 DOM 标记，阅读模式同样适用 |
| `DocumentSessionPlugin` | 光标及滚动会话保存与恢复 |

新增、编辑、删除即时改变文档草稿，撤销使用已有编辑器历史；显式保存继续保存
整篇笔记。网格插入未确认前关闭、Escape 取消缩放、结束多选和失效异步操作都不
提交新内容。不存在需要另设的行级“保存/取消”表单，也没有业务必填、唯一键或
重复行约束；空单元格、重复文字是有效笔记内容。

审查 `src` 和产品脚本的事件生产者，确认旧 `sortAsc/sortDesc/filterContains/
paginate/autoFitWindow/autoFitContent/borderPreset` 分支没有可达产品入口。
其中旧筛选会直接删除不匹配行，旧分页复用/移动原节点；移除这些危险遗留分支，
不新增排序、筛选或分页功能。现有列宽双击适应内容保留。

## 已复现问题与根因处理

| 问题 | 根因及修复 |
| --- | --- |
| 行/列移动菜单无效 | 已有菜单命令未接处理器；接入共同模型的原子移动 |
| 删前一行后选区错位 | 选区保存 DOM/数组下标；改存所属表与单元格节点键 |
| 表头不能多选 | 旧命中仅识别 `TD`；`TD/TH` 统一处理 |
| Ctrl/Cmd 拖动重复追加、计数失真 | 每次 mousemove 追加新矩形；一次手势只更新一个区域，去重实际单元格 |
| 滚动后多选框覆盖正文或冻结区 | 选框位于表格外层；显示几何与表格真实视口、冻结行列相交，隐藏部分不再绘制，选区数据不变 |
| 合并丢失内容、跨度和空行错误 | 旧物理索引循环重复删除；按逻辑网格预检，完整移动所有子节点并保留被跨度覆盖的行 |
| 插入/删除/拆分跨合并单元格损坏 | 物理 children 下标不代表逻辑列；按跨度单次调整，迁移仍存活的锚点内容 |
| 列宽顺序与列数据不一致 | 统一维护 `colWidths`；修正锁定 Lexical 插列助手的边界位置 |
| 缩放邻列压缩未操作的合并区 | 缺省列宽不能直接回退；先保留已存宽度，再按合并单元格跨度总宽分配尚未测出的逻辑列 |
| 旧版本表格插删后合并区宽度错误 | 历史数据仅有 `cell.width`、没有 `colWidths`；结构操作前统一推导已知逻辑列宽，插删、合并、拆分和移动后同步。无法确定的列保留自动宽度，不填入默认数值 |
| 拖放和缩放旧会话仍可写入 | 绑定节点键、结构签名及可写会话；文档/阅读模式/卸载/失效目标即取消 |
| 缩放取消或撤销残留 DOM 宽度 | 预览与持久状态分开，逐项恢复本手势仍拥有的样式；完成才记一次历史 |
| 自身悬浮按钮消失 | 控件被当作离开单元格；保留本控件及选择-only 更新的可达性 |
| 异步粘贴覆盖更新后内容 | 绑定选区 epoch、表结构与内容快照；内容更新后即失效，包括编辑再撤销 |
| 重复粘贴和部分截断 | 同步请求锁；全目标预检，越界/合并重复映射整次拒绝，失败可重试 |
| 多编辑器事件串写 | 生产事件从所属根冒泡，按最近编辑器归属处理；legacy 全局事件仅明确归属时接受 |
| 菜单关闭/只读/换文档后旧回调 | 打开时捕获会话和结构，执行前重验；Escape/键盘导航/焦点移出按同一规则处理 |
| Excel 空表、超范围或重复读入 | 复用原导入预算，展开前验证实际有效区域；高起始行的一格数据不误报空表；一次读入原子提交 |
| Excel 读取期间位置改变或正文更新 | 保留启动插入点；正文更新、换文档、只读、卸载时拒绝旧任务 |
| Excel 绕过禁止嵌套表格规则 | 实际 `TablePlugin` 默认 `hasNestedTables=false`；Excel 对文字、表格及装饰节点选择均检查祖先，遵循已有策略 |
| 表格光标快照为 null | `TableCellNode` 为 shadow root；沿物理祖先找到根，保存精确子路径与点偏移，普通段落格式兼容 |
| 阅读另一笔记时写入前文档光标 | 每次会话使用当前文档自己的 selectionRef，pagehide 不再把 A 的单元格路径保存给 B |
| 状态栏残留多选状态 | 所属编辑器观察与文档/模式重置；不改原有保存协调 |
| 已保存颜色、表头和隔行状态未显示 | 移除强制首行/隔行覆盖；明确表头和条纹开关，内联颜色优先 |
| 深色主题浅色单元格文字不可读 | 从既有背景色派生具有足够对比度的默认前景，保留用户显式文字格式；派生样式不写入文档 |
| 列宽被文档默认 min/max 限制 | 默认紧凑文档密度保留；显式保存的列宽使用 70–600px 原范围 |
| 冻结状态保存但不起作用 | 原冻结 DOM 标记仅在可选横向 wrapper 分支设置；按当前表格滚动结构派生标记，逻辑首列兼容 rowspan |

合并移动仅在所有合并区域保持连续、锚点不倒置时执行。无法保持有效网格的移动
原子拒绝并说明先拆分；不会移动部分行后才失败。删除最后一行/列后保留可编辑正文。

Excel 继续使用原 5 MB 文件上限，表格内容复用原 renderer 导入的 4,000 单元格、
20,000 节点、10,000 行、2 MiB 预算，未缩减既有导入限额。超出限制不会静默截断。
