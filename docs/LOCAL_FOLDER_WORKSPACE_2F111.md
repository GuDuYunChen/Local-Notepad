# 2F.111 / 4.244.0 本地文件夹整理工作台

接受基线master `b0d02d0f1b29054390f55608904e253343e64421`、树`9b3701e7318d902554da4d012a81eb2152fc7bb8`为已合并的2F110/4.243.0。本文记录完整范围，不预先宣称产品CI或Windows通过。

## 入口、操作、结果

设置 → 标签与分类 → 打开文件夹整理。读取完整目录元数据，在当前目录查找/50条分页，浏览根目录和上级；最多100个明确选择跨目录保留。浏览目标后预览整批移动，确认后单事务提交，结果显示已确认的新目录。新建/重命名普通文件夹也先确认，不覆盖或合并同名项目。排序保留原有负值兼容，较高顺序的新项目靠前。

只允许真正没有任何子项的普通文件夹移入原回收站，不永久删除或递归删除。模板/回收站项目不参与可移动列表，但参与版本、同名和空目录保护；隐藏项目不是不存在。移动文件夹保留后代的相对父关系，拒绝祖先与后代混选、循环目的地、同目录空操作和并发结构变化。普通笔记打开沿用原保存/放弃/取消保护，不增加正文写通道。

## 一致性与异常

SQLite写事务先取得写锁，再核对完整元数据版本、全部选择和目的地，任一拒绝整批不写。只更新选定行的目录字段，或创建空文件夹；不读写笔记正文、标签、附件、版本历史、保存回执、置顶状态。原编辑器保存仍由原事务和退出保护负责。

首次POST前持久化本机操作记录并逐字读回；配额/读取/读回失败不发送。停止等待、关闭或超时不等于数据库回滚，保留未确认记录；重启后只能只读核对当前状态，不自动重放。状态一致也明确不是历史回执。结束记录或清除损坏记录需单独确认且身份相同，不能清除其它窗口替换的记录。外部变化撤销旧确认/过时结果，输入保留；已确认操作后其它位置再变化不覆盖新视图。清理本机记录失败仍通知原资料树刷新。

限制为20000条普通+隐藏目录行、2MiB元数据、单名称4000字节、单请求64KiB；超过限制、结构断链/循环或不完整结果拒绝，不显示部分成功。新名称1–255Unicode字符，禁止路径/控制字符和模板前缀；保留大小写但同名判定沿SQLite ASCII NOCASE。该工作台操作的是应用数据库目录，不是任意本机磁盘目录，也不推断或修复既有坏结构。

## 验证与边界

单元/实际HTTP/SQLite事务验证完整版本、并发写锁拒绝、第二行故障回滚、隐藏子项、重复请求、取消、非法请求、原关联与正文不变。真实Settings与原guard测试确认导航所有权、取消、焦点和异常。浏览器DOM测试不是Windows点击证明；须新包原生及原所有模块/29安装生命周期的来源、报告和截图复核后接受。
