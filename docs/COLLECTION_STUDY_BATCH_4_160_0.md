# 4.160.0 — 阅读批注批量整理与安全撤销

基线：`feature/ui-redesign-v1` / `4ac043b42edad5d62a5999979b03f9f9fd50f9e7`（4.150.0）。保持原编辑器、正文保存确认与资料集格式，不修改 master、数据库或正文，不新增第三方依赖。

## 用户流程

全局检索 → 阅读批注 → 逐条选择或“选择本页批注” → 翻页继续选择 → 指定未读／已读／待复看 → 预检批量标记 → 查看来源与前后状态 → 确认批量标记 → 查看实际完成数 → 撤销本轮或结束本轮并保留当前状态。

每次最多 200 条，超过上限整次拒绝新增选择，不静默截断。同一笔记在不同资料集中分别选择和处理。翻页保留选择，更换筛选、刷新和切换页签清空选择，避免处理被隐藏的旧范围。排序也属于筛选条件。

## 保存与撤销边界

- 只改人工阅读状态，完整保留批注文字与书签，不切换或保存正文。同状态条目不写入、不更新保存时间，也不创建空记录。
- 所选条目存在当前窗口未保存批注时，预检和锁内写入都拒绝操作；非所选草稿不改动。同一资料集的未选草稿可能因已存记录更新而提示版本冲突，这是保留草稿而非覆盖的保护。无法读取其他窗口尚未保存的内存草稿。
- 预检核对工作台完整快照、来源身份和阅读记录版本，确认时再次检查。预检期间改变筛选不会显示迟到的旧确认框，重复确认不能重放同一预检。
- 保存按资料集分组，同一资料集单次原子写入；跨资料集不是全有或全无事务。失败或取消时保留成功项，显示已修改、原状态相同和尚未修改数，可撤销已经完成的标记。
- 沿用阅读记录的同源 Web Lock，不使用不安全的无锁回退；取消信号传递至等待中的保存锁，锁内还会检查取消状态、来源版本和草稿。
- 撤销只作用于本轮实际变化的条目。某份资料集之后有保存、书签更新、导入、来源变化或所选草稿时，跳过整份资料集，保留新内容；继续尝试其他未变化的资料集，并显示未撤销数和原因。不会用旧整份记录覆盖新批注。
- 已成功撤销的组不会再次执行，取消或失败部分可以再试。撤销本身是一次人工状态保存，更新时间会变化，不恢复历史保存时间。
- 一次检索窗口只保留一轮撤销记录；开始下一轮前需撤销或明确结束本轮。关闭检索窗口后不再有本轮撤销入口；已保存状态仍然保留。不是持久化操作日志或崩溃恢复。
- 工作台有损坏或缺少来源的记录时，暂停批量操作，保留原有诊断，不自动删除或重建记录。
