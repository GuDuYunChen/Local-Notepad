## 入口与使用

同步中心增加「同步诊断摘要」，在未启用、尚未读到状态或发生错误时也可使用。点击「生成诊断摘要」只读取父组件当前持有的信息，不发 API 请求、不刷新状态、不运行预演或同步。用户先阅读只读文本，再点击「复制诊断摘要」，或通过「选择摘要」手动复制。没有自动上传或发送入口。

报告区分生成时间、最近状态读取时间、最近同步尝试和最近确认成功（均 UTC），以及未读取、正在刷新、保留旧结果等状态。展示已知的 provider、启用/自动同步状态、间隔、恢复状态、基线和冲突计数及错误标记。状态计数和已读取列表数量不一致时分别列出，不猜测哪一个正确；缺失或非法数值不改成零。

根据已记录状态提供固定的下一步参考。写入中 / 结果待确认优先提示核查两端、不反复写入或重新绑定；不会解析错误原文来猜测 DNS、密码或数据库故障原因。这不是自动修复，也不改变原有确认、重读、浏览代次或恢复保护。

生成后保留同一份快照。后续观察到报告中的字段变化会提示重新生成，恢复原值不会自动更新旧摘要。隐私字段不参与报告比较，因此此提示不是完整配置变化检测；报告始终明确不是实时状态保证。

## 分享边界

采用字段白名单构造，不做“替换几个关键词后导出原始 JSON”。报告不包含正文、标题、附件名、对象 / 设备 / 仓库编号、用户名、地址、密码、令牌、哈希或原始错误文本；错误只输出是否存在的标记。provider / 状态枚举仅接受固定自身键，时间、布尔值、计数严格检查类型和范围。任意附加字段不会进入快照或剪贴板。

保留的计数和时间仍可能透露使用情况，因此明确要求用户核对后再分享，不宣称匿名。报告只在组件内存中保存，收起或卸载后释放组件状态，不写 localStorage、文件、数据库或远端。父组件仅新增 import 与只读子组件，不改动操作处理函数。

## 剪贴板边界

只有显式点击复制才调用标准 clipboard API。重复点击单飞，等待最长 5 秒；拒绝、缺失能力、抛错或超时均提示复制未确认并提供手动选择，不自动重试，不传播错误原文。收起、重新生成或卸载后，迟到结果不能更新新视图的提示。

浏览器剪贴板写入没有撤销能力，结束等待不代表取消原请求；界面会说明先前请求仍可能完成。这些复制操作只涉及用户已经看到的摘要，不会执行同步写入。
