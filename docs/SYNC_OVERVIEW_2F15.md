## 用户可见的改进

同步中心顶部新增「同步总览」，集中说明当前需要先做什么。总览优先保留写入待确认、恢复阻断、预检暂缓、状态读取失败和未保存草稿等已有证据；正常读取不等于两端一致，不显示无依据的“同步健康 / 全部同步完成”。状态计数与已读取列表计数分开显示，未知不是零，最近确认成功和状态读取时间均明确使用 UTC。

提供五个固定分区入口：状态与恢复、连接配置、预演与执行、冲突队列、诊断摘要；页面底部可以返回总览。用户点击只移动到当前中心内的区域并设置键盘焦点，不自动点击区域内的按钮。未启用时不开放不存在的执行区域；没有可定位队列时注明原因。只读浏览在任务等待期间仍可使用，不改变操作锁。

总览随已读取字段变化更新，但不自动滚动或抢焦点。导航保留正在输入的连接草稿、诊断快照及冲突对照与确认；原有队列排序 / 翻页仍按各自规则撤销旧确认。用户最终执行和解决冲突仍走原来的独立按钮、确认、复核及写入路径。

## 实现边界

- 复用已经修正的 `syncDiagnosticFacts`，只使用固定状态、布尔、计数和时间。不把正文、标题、附件名、端点、用户名、设备编号或错误原文传入展示模型。
- 最近状态与结构化恢复详情独立考虑。详情缺失或矛盾时保留警示，不从旧成功记录反推当前完成，不凭空生成重试时间。
- `focusSyncOverviewRegion` 只接受六个固定内部目标（含返回总览），只在传入且仍挂载的中心内查询。嵌套的其他中心、卸载 / 隐藏 / 不可聚焦 / 已移除目标均不能作为替代目标。不从任意字符串构造外部选择器，不导航 URL。
- 父组件增加根引用、只读子组件、可聚焦区域标记和返回按钮；既有状态读取器、exclusive、预演停止、同步 / 冲突处理、复制和后台任务回调保持原代码。
- 不新增接口、网络请求、文件操作、剪贴板、持久化状态、自动启用、自动重试或批处理。
