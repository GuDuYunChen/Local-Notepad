# 2F.115 / 4.248.0 本地历史检索与对照中心

## 基线与完整范围

上一阶段4.247.1已在masterca1a6c64完整验收合并。本轮从已有全库目录、版本历史和逐行比较能力组织一个完整本地工作流；不是重做旧版本恢复，也不是小控件扩展。入口：设置→标签与分类→打开历史中心。

一次交付包含：完整普通笔记目录的搜索/分页、明确选择笔记、完整保留历史元数据索引的搜索/分页、明确选择历史快照、与当前保存正文在同一SQLite只读事务读取、文字投影/原文逐行差异、跨页定位及再次定位、通过原保存保护打开来源、明确隐私确认并重新核验后导出、取消/超时/失败重试/变更后拒绝、当前版本原生和完整安装验收。

历史中心不恢复/删除/清理任何版本，不创建笔记或新增正文写入接口。需要恢复时打开当前笔记，再使用原编辑器已有版本历史与原保存、冲突、草稿及退出保护。schema14与依赖图不变，云/多端不启动。

## 数据边界

- 目录复用原完整只读folder-workspace索引，仅普通活动笔记；模板、文件夹和回收站不作为历史来源。
- `GET /api/history-review?file=<id>`只选择当前笔记，返回全部保留历史元数据，`selected:null`；绝不将当前正文伪装成一个历史版本。用户明确选快照后使用`&version=<positive integer>`。
- 当前正文、完整历史索引、所选历史正文来自同一只读事务。最多500份保留元数据、正文每侧512KiB；超过预算明确拒绝，不截取成“完整”结果。元数据可显示超限快照但不能选择它，仍可选其它预算内快照。数据库正常仅保留最近版本，本中心不声称完整编辑审计。
- 身份、所属笔记、UTF8、字节数、摘要、时间和元数据顺序均核对。相同时间以版本ID降序区分；没有历史明确显示空状态。
- 文本投影沿用原保守解析：未知节点明确不可投影，原文仍可访问；最多2000行/30万计算单元，超预算没有部分差异；HTML始终作为文本显示。
- 导出默认为计数/范围，不含笔记标题、标识、路径、历史时刻或正文。明确勾选才包含所选快照及当前两份完整正文，不包含其余历史或附件。下载前重新读取相同快照并比较全部来源；清理、改名、保存等变化拒绝下载。
- 打开仍经过原`useGuardedNoteOpener`，使用新读取的当前保存正文校验；原取消保留中心，接受才关闭。打开期间让原保存决定位于前景。快捷键、输入法及焦点不触发后台保存。
- 当前请求同步所有权、AbortSignal和超时相互配合；取消或关闭后迟到结果不写状态/不下载/不导航。不自动重试失败或执行写入。
