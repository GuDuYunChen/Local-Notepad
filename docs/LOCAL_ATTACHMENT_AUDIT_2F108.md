# 2F.108 / 4.241.0 本地附件检查中心

接受基线 master21f987b4 / tree d94148952c1dd38110253535533f20e65b7dd761；2F107已验收合并，不能把旧73/74失败当当前故障。本模块是一个完整只读检查工作流，不扩展云/多端同步，不做附件删除或自动正文替换。

## 入口、操作和结果

设置 → 数据与备份 → 打开附件检查中心。读取已保存普通笔记、模板、回收站正文与附件目录的直接条目，展示普通文件、缺失附件、未发现候选引用及非普通条目。支持文件名筛选、状态过滤、问题/大小/名称排序、附件与来源各50项分页。普通来源通过原保存保护导航打开；模板和回收站仅标明来源，不自动恢复。

解析缺口和不支持URL单列，能定位对应来源。报告导出需明确确认，默认只有汇总、范围与边界，不含文件名/标题/查询词/正文/绝对路径；显式勾选才附当前筛选的文件与来源元数据及覆盖缺口来源。取消导出不下载，下载失败保留确认和结果供重试；发起下载不冒称磁盘写入已确认。

## 严格口径与读取边界

这是“可识别候选URL + 稳定目录元数据观察”，不是完整引用证明、磁盘文件完整性、病毒检测或清理建议。文本/代码中的字面路径亦可计为候选；草稿、历史版本、外部资料与附件内容不在范围，未发现引用绝不等于可以删除。模板和回收站当前保存正文纳入范围，避免直接漏算隐藏引用。JSON编辑器中的src/url/href及文本路径、普通文本本地路径被识别；损坏/超深/过大结构的解析缺口明确显示。

只解析 `/uploads/<单层名称>` 或回环host的HTTP(S)对应路径；远程、协议相对及任意本机路径不作为本地引用，不发网络请求。拒绝路径穿越、双重编码/编码分隔符等，查询/片段不作为文件名。附件目录由应用配置，不接受请求中的任意路径。os.Root固定目录身份，仅用Lstat枚举直接条目，不打开附件内容，不跟随链接、不递归目录；非普通条目标记未跟随。缺少目录视为空且不创建；读取出错或目录观察变化拒绝整次结果。

正文来自单个只读SQLite事务，附件列表前后元数据和根身份必须相同。这不宣称SQLite与文件系统间原子快照，不检测同大小同时间戳内容替换；报告只证明观察范围，须重新检查变化后的资料。上限10000个文件/缺失条目、20000篇保存正文、合计64MiB正文、单篇16MiB、50000组候选引用、2MiB笔记元数据及8MiB报告；超过上限不返回误导的部分统计。接口8秒/客户端10秒截止。

## 异常、交互与保护

取消或关闭中止请求并隔离迟到结果；重新检查不沿用旧部分结果或旧成功提示。应用资料变化事件使结果过时，取消导出确认与待导航，要求重新检查。外部文件系统变化并非实时监听，用户需手动刷新。错误/成功/导出确认位于列表滚动区之外；最小窗口、键盘Tab、IME Escape、Ctrl+S隔离和焦点恢复分别验证。保存/草稿/回执/退出六份源码、schema14、依赖图保持。
