## 用户可见变化

同步总览当前提示下新增“查看相关帮助”。未启用或有配置草稿时定位首次配置；准备预演时解释检查/预演/执行的区别；冲突或计数不一致时定位冲突核对；写入待确认、等待、旧读取、恢复保护、暂缓、未知或错误时定位状态与恢复。它是文档入口，不是新增状态诊断，也不建议绕过原有保护。

仅在用户点击时，展开本总览已有的帮助及对应主题，并把焦点移动到主题标题。再次点击不会收起主题，也不会关闭其他已展开主题。后台字段更新只更新入口文字，不自动展开、不抢焦点。独立的总览实例不互相定位。

目标缺失、已卸载、隐藏、处于 inert 区域、属于其他总览或不是原生 details/summary 时拒绝。焦点失败时恢复本次尝试前的两项展开状态，不点击替代按钮、不访问另一实例。没有新增请求、IPC、存储、剪贴板、重试或同步写入。

## 本阶段原生验收修正

首次提交 `eae88ab` 的专项 Node 26/26 与真实 React 15/15 已在 Windows 通过，但原生场景在深色主题失败：新入口声明的 `--ink` 被全局 `html[data-theme="dark"] .btn:not(.primary):not(.danger)` 的 `--ink-soft` 覆盖。其实际对比度仍大于 4.5，但未达到此组件约定的主题令牌，因此没有放宽颜色检查来通过。

修正仅增加此入口范围内的更高优先级文字颜色声明，不修改全局主题、色值、其他按钮或业务逻辑。原生检查保留颜色令牌与对比度要求；同时剔除收起主题内不可见文本的采样，并要求观察到 React 已提交的新快照标记之后再验收展开状态与焦点保留，不能只等待固定毫秒后推测更新完成。新增拒绝未观察到快照更新的 Node 用例，本地合计 27/27。最终验收以包含此修正的新 HEAD 为准；首次提交的原生失败不能被忽略。
