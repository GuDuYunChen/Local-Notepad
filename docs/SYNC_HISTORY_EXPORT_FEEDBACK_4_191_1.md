# 4.191.1 - 导出提示生命周期修复

基线: 35ec5cb2b0297fba10019c2edf7a62f6a0445087 / 4.191.0。
继续 feature/knowledge-os-phase2 和 Draft PR #2，不合入 master，不推进下一功能阶段。schema 14 不变。

## 复查发现

基线完整 1788 项界面测试通过，旧交付包、原始报告、实际下载文件及安装包重新校验通过。新交互测试仍发现一个遗漏: 导出提示只在条件不同的时候隐藏，没有真正失效。

改变文字、对象类型或处理结果再回到原条件，会重新显示旧下载或失败提示，而没有发生新的下载。同样的问题影响输入法取消回原查询、读取再次失败和再次停止读取。这是旧操作反馈重新出现，不是已观察到的重复下载或正文数据损失。

## 修正与边界

快照、查询、对象类型、处理结果、读取阶段或组合输入状态发生已提交的变化时，在绘制前丢弃旧反馈。以后条件相同也不会恢复它。普通父组件重渲染保持现有反馈；只有新的明确导出操作产生新的提示。

不改变下载函数、JSON 格式、筛选规则、输入法确认逻辑、2000 条/4 MiB 上限。仍然只提示已请求下载，不声称确认落盘。App、TextEditor、自动保存、Ctrl+S、引用维护、退出保护、后端和依赖不变。
