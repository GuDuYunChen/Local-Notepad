# 2F.110 当前模块收尾：原导航接受回执与 React 提交时序

真实 Windows #81/run40730674565 的全部旧模块通过，但快捷操作首次导航到最近访问后面板仍停留，显示“页面已变化，未继续执行原操作”。原报告、截图及 artifact12835740668（2924062 bytes，SHA256 95481454100a1cf7707543931f5508344a20153338b364004f63476b59852111）保留，不能宣布当前模块已验收。

原始服务在原 changeWorkspace.afterChange 中成功解析 Promise，但实际浏览器可先提交工作区、执行 contextVersion 效果，再恢复 await；效果误将该成功请求视为外部变化并中止。原 async act 将两者合批，未覆盖此顺序。增加真实 App 的同步 React 提交回归，旧实现三项清洁工作区、设置子入口、原放弃确认负例均失败，十一项原控制通过。

修补只为原功能已接受的结果增加同步、按请求与目标身份匹配的一次性通知，组件在原导航提交前消费该回执。Promise 仍保留；关闭、外部变化、取消、子入口异常及迟到结果不得产生成功通知或再次执行。原保存/放弃/取消决策、导航时点、正文、草稿、退出保护保持，不将 contextVersion 失效检查删除或放宽。
