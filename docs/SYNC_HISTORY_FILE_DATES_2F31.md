## 功能

离线查看历史文件中新增默认收起的“按文件内处理日期筛选（UTC）”。复用现有SyncHistoryTimeFilter和日期编译规则，仅追加明确的文件范围文案。原本机历史组件的默认文案和行为不变。

可选全部日期、起止日期范围或仅时间缺失；任一边可留空，结束日期包含当日最后一秒。使用处理/失效时间，不替换为创建时间，也不使用机器本地时区。日期条件先编辑，点击应用或普通Enter后才生效；不拦截Ctrl+S。日期未应用时文件列表、匹配概览和当前页不变。倒置/不存在/空范围拒绝，不改掉已有的有效条件。

日期与文字、对象类型、历史处理结果取交集，先筛选整个已验证文件再分页，匹配概览用同一组条件。更改已应用条件回第一页，重复应用相同值不无故跳页。仅缺失模式不伪造时间范围。零匹配仍只是文件内结果，不称为工作区或全历史为空。

“清除文件内筛选”同时清除日期草稿和应用值，保持日期面板折叠状态与既有焦点规则；不清除上一次读取失败的来源说明。新文件成功读取重置本地日期，防止旧条件隐藏新文件；失败/取消/停止保留旧文件及两层日期状态。文件声明的原导出范围和上方本机历史始终不变。

无新增网络请求、FileReader重读、存储或下载。解析器、历史JSON v1/v2格式、导出、依赖锁、后台、自动保存/回执/队列/引用/退出协议均不改。
