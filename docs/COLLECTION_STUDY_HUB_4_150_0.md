# 4.150.0 — 跨资料集阅读批注工作台

基线：`feature/ui-redesign-v1` / `ab0caec7d83a71c3de2d14dbb0509c8bca8b2245`（4.140.0）。不改动 master、数据库结构、正文、旧阅读记录或备份格式；不新增依赖。

## 完整使用流程

全局检索 → 新增“阅读批注”页签 → 搜索已存批注或筛选待复看条目 → “查看并编辑此批注” → 自动选择正确资料集、展开阅读面板、翻到目标所在页并聚焦批注编辑器 → 使用原保存按钮明确保存。

同名资料集以及同一笔记在不同资料集中的记录分别保留，按资料集身份与笔记 ID 联合定位，不合并批注。进入编辑器不会打开、切换或保存正文。来回切换保留既有未保存批注草稿；工作台只显示已保存内容。

工作台默认“只看有批注”，可取消后浏览未读／已读／待复看全部历史条目。支持资料集、状态、关键词组合筛选，关键词匹配批注、标题、历史目录、笔记 ID 和资料集名；支持 NFC 规范化、不区分大小写的字面查询。排序可选最近保存或资料集原条目顺序，每页 12 条。三个主页签支持左右方向键、Home、End，不拦截中文组合输入。

## 统计范围与异常提示

汇总读取当前本地资料集以及各自已存阅读记录，不读正文，不重新执行资料集检索，不计入未保存批注草稿。相同笔记跨资料集分别计数，未存阅读标记按未读处理。页内筛选只改变显示，不改写任何记录。

每份资料集读取失败、损坏或指纹不符时，显示原因与存储键，并明确说明只有成功读取的资料集计入统计。缺少来源资料集的阅读记录单独诊断，可能是删除历史或恢复暂存；不把它当成有效批注，不自动清理，不猜测重建来源。存在异常记录时暂停清单导出，避免将部分结果包装成完整备份。

汇总前后对相关键和原始值进行一致性检查，期间有变化则整次汇总失败。保存、导入、删除通知以及同源 storage 事件使已有快照过期；重新获得焦点、定位和导出时再检查实际原始值，不只依赖事件。用户手动刷新后才使用新快照；取消、关闭或重开期间的晚到结果不能覆盖新视图。该机制不是跨标签页数据库事务，不保证对外部非协作写入的线性一致性。

## 清单导出

Markdown／JSON 导出包含当前筛选的全部分页：资料集身份、笔记 ID、历史标题／目录、原序号、人工状态、已存批注、保存时间和书签标识。包含筛选条件和读取时间，不含原始资料集字符串、正文、命中节选或未存草稿。超出 8 MiB 明确拒绝，不静默截断。

这是便于回看或分享的阅读清单，不是可恢复备份；迁移仍使用 4.140 的配套便携 JSON。文件未加密，可能含私人批注，应注意分享范围。人工已读不代表正文已经核验；仍沿用上一版正文变化不自动重置标记的边界。
