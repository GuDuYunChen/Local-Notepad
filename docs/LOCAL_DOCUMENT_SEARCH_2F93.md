# 2F.93 / 4.226.0 本地文内查找与安全替换

基线30ba716 /4.225.0（PR2验收6186029766），不重做已完成反向链接。完整模块：Ctrl+F/H与原编辑器入口→当前正文查找→大小写/整词/中文输入→上下匹配和上下文→单项替换或批量数量确认→当前草稿结果→原撤销/重做/保存/重开。取消或文档、条件、正文变化均不能应用旧确认；只读编辑器不开放替换。没有云端/多端功能。

原实现有Unicode小写扩展导致位置偏移、非BMP整词边界错误、跨加粗文字找不到整句等三个独立负对照。新匹配使用转义的Unicode字面量正则和原UTF16位置；替换值中的$&、$1和反斜线不作正则替换。整词按Unicode字母/数字/组合符/连接符边界，不是中文分词。相邻普通文本叶可跨加粗/斜体，不跨段落、链接或单元格边界；链接显示文字可替换但不修改地址。代码块原文可查找替换；Wiki引用、token节点、图片/附件和隐藏嵌套编辑器不在范围。

只改当前Lexical草稿，用HISTORY_PUSH_TAG形成一次撤销边界；没有第二条数据库保存通道。原App/TextEditor保存、自动保存、不可变回执、草稿、引用维护和退出规则保留。批量替换前确认数量，最终在同一原编辑器更新中重新比较完整文档签名与单调修改代次，预先计算全部节点结果；不接受过时确认、任意部分匹配或只读写入。跨样式匹配的替换文字采用起始叶样式，未匹配文字及链接地址保留。替换结果提示仅称草稿改变，不伪称已保存。全部同值替换不改正文。

查找不抢输入焦点或改写内容；支持CSS Highlight时高亮当前匹配，不支持时仍提供上下文和段落定位。原代码块查找事件保留。查找与替换的输入组合期间不筛选/导航/提交；新笔记生命周期清除上一笔记面板、确认和迟到帧。确认弹窗在document.body，避免旧浮层backdrop-filter裁剪；新的字体/窄屏规则覆盖旧360px最小宽度/9px按钮字样，不改别的搜索面板。
