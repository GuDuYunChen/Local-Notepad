## 可执行约束（本轮开始采用）

这些是助手操作规则，不是假称新增了能拦截平台全部工具调用的中间件。

- 一个发布批次只处理一个有边界的修补；先做本地反例与回归，再一次性提交。成功运行不因缺少聊天最终回复而重跑。原工作流和测试门槛不删除、不改成只测文档。
- 同一run的状态观察间隔至少90秒；状态未变不重复下载、展开原始日志。只取失败job的日志。每次进入等待前先留下短检查点，不用连续轮询撑满会话。
- 每个故障链最多一次有依据的手工重试；输入未变且无新证据时为零次。工具安全拒绝不走替代路径；权限/接口不支持与网络瞬断分开判断。
- 每轮达到30次外部连接器调用前必须检查预算并给出进度；不是为了“做完”再展开整批无关产物。预计无法完成剩余验收时，交付准确待办而不是没有结尾。此预算不把尚未完成的CI变成成功。
- 写入回执不明先读远端HEAD/目标文件，不重复写；已完成产物以ID和摘要复用。证据记录放本地交付文件和PR评论，不为了写一句“已验收”再造一个源码提交、重启整套CI。
