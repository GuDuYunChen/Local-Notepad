## 新交互

离线历史文件每条记录新增“只看此对象记录”。它使用该记录已经验证过的完整对象标识，对整份已接受文件做精确对象限定，再与文字、对象类型、处理结果、UTC日期条件取交集，然后稳定排序、分页。

对象标识按不透明身份处理：不做大小写折叠、全半角转换、Unicode归一化、trim或子串比较。例如“对象-Ａ”“对象-A”和前后带空格的标识互不等价。按钮不会把对象ID写入查找框，也不会改变文件声明的原导出条件。

启用后在查找区域显示当前完整对象标识和“取消对象限定”。单独取消只移除对象限定，保留文字/类型/处理结果/日期草稿与已应用日期、排序；完整“清除文件内筛选”仍一次清除所有文件内筛选。限定变化回第一页并收起旧页标识；同一对象重复点击为无操作并保持按钮焦点。失败、取消或停止文件替换保留旧对象限定；新文件成功读取、清除查看结果或重挂载会清除。
