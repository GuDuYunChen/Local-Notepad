## 使用入口与行为

侧边栏“搜索笔记”或 Ctrl + Shift + K 打开全局检索；Ctrl + K 保留快速切换，并提供携带当前关键词的“完整检索与筛选”。原 Ctrl + Shift + F 字体快捷键不变。

- 搜索标题、普通正文、代码、WikiLink 标签、图片说明和公式源码。只读取白名单展示字段，不搜索 JSON 属性名、图片 URL 或链接目标 ID。
- 使用 Unicode NFC 规范化的字面短语，默认不区分大小写；百分号、下划线、正则和 FTS 符号没有特殊语义。不提供语义、拼音、分词或模糊检索。
- 按目录（含子目录）、来源、修改时间、置顶组合筛选，按标题优先、最近修改或标题顺序排序。
- 每页 20 篇，可翻到全部匹配记录；显示笔记总数与正文命中次数，标题命中不混入正文次数。每篇最多返回 3 段节选，节选限制不截断计数。
- 选择结果先看上下文，普通正文节选可“定位第 N 处”；代码、标签、图注、公式只提供打开笔记，不模拟字符定位。
- 开始定位前重读正文并校验 SHA-256，随后交给已有保存／不保存／取消流程。只有用户接受打开后才创建定位请求；取消返回原检索条件，保留草稿。
- 原文变动、删除或定位无法映射时拒绝猜测；复用既有编辑器就绪、折叠展开与只读保护。修改中的同一篇笔记仍可能被编辑器拒绝旧位置，不会覆盖其草稿。
- 同一窗口中保留检索条件，关闭取消请求并释放结果节选；重新打开重新读取。条件不写入 localStorage，不跨重启保存。
- 旧快速搜索同时修复失败被当成空结果、IME 回车误打开，以及加载期间可以打开旧结果的问题。

## 数据与性能边界

新增 GET /api/search，仅执行固定 SELECT。目录元数据与正文在同一个只读事务中读取，正文逐行处理；浏览器只接收当页元数据与有界节选，不接收整库正文。

每次检索生成范围版本指纹。翻页携带版本，资料库变化则提示重新搜索，避免把不同状态的分页拼成完整结果。标题、路径、删除和同秒正文修改均参与相应校验。

查询为本地后端扫描，不是持久化增量全文索引；10 秒超时后明确失败，可缩小目录、置顶或时间范围重试。当前实现仍会读取活动笔记行，范围筛选主要减少正文解析量，不承诺超大库恒定响应时间。

检索不包含未保存草稿、回收站、模板、外部附件文件内容或核对存档。不可解析正文会统计并警告，标题仍能匹配；缺失父目录、循环目录或已删除祖先下的异常条目不纳入正常目录检索，此版不修复目录结构。

无数据库迁移、正文改写、自动替换、新第三方依赖或 master 修改。
