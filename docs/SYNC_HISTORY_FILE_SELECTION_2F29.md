## 新增交互

设置 → 同步中心 → 同步总览 → 离线查看历史文件。在完整读取和验证文件之后，出现“查找文件内记录”：按标题、对象标识、记录标识进行字面查找，可组合对象类型和当时处理结果。

先筛选整个文件，再按每页 25 条分页。因此第一页输入查找词也能找到原本位于第 80 页的记录，不把仅搜索当前页当成文件内搜索。沿用既有 Unicode 规范化/大小写处理，不解释正则表达式或 HTML。显示“当前匹配 X 条 / 文件内共 Y 条”，保留原文件声明的导出条数、当时已读数、日期范围和来源状态；不会把 Y 称为整个工作区的历史总数。

条件变化回到筛选后的第一页并重置列表滚动，不抢走输入焦点。无结果不显示“第 1 / 0 页”，两侧翻页均不可执行，并明确只是本文件没有匹配。清除文件内筛选恢复当前文件全部记录，不清除文件查看结果，也不删除或重读文件；键盘清除后焦点返回查找框。

输入法候选文本与已确认查找条件分开。选字期间保持完整候选文字和上次结果/页码，确认后才应用最多 128 个 Unicode 字符的限制；普通文本即时筛选。取消并回到同一条件不重置当前页，清除后迟到的 compositionend 不恢复旧候选。无需新增确认按钮或拦截 Ctrl+S。

新文件读取成功后重置文件内条件和页码，避免上一文件条件把新内容全部藏住。取消选择、失败或主动停止保留原文件及其筛选/页码，显示原有旧结果说明；更晚的旧请求不能覆盖新文件的条件。清除查看结果或卸载后不保留查询词。
