## 使用入口与行为

项目 → 结构 → 实体智能分析 → 正文证据回看 → 打开证据章。
编辑器核对栏新增“核对备注与待修改清单”，默认收起，不遮挡正文。

- 每章可填写最多 2,000 个 UTF-16 单位的备注；随输入记入本轮内存，不自动改写或保存正文。
- 标记“待修改”清除本章“已核对”，并禁止直接标记完成。取消待修改后仍需明确标记已核对。
- 修改正文清除已核对状态，但保留备注和待修改项。备注不等于自动推断的人物关系或永久校对结论。
- 清单可按未核对、待修改、已核对、有备注筛选，并搜索章节名和备注；每页 8 章。状态筛选仅影响清单展示，不改变原来的证据核对范围。
- “下一未核对章”跳过已核对章节，包含待修改章节，末尾最多绕回一次，不重复打开当前章节。仍经过原来的未保存确认，失败或取消不推进位置。
- “导出本轮清单”导出完整进入时范围的 Markdown 文件，包括章节 ID、标题、人工状态与备注，不受清单分页或状态筛选限制；不读取或附带正文节选。
- 清单记录进入时的范围与标题，不声称已经重新检查最新正文。Markdown 特殊字符与 HTML 转义，用户备注不能成为主动脚本或伪造章节标题。
- 证据列表页也可查看、导出和结束当前核对记录。章节问题只能在对应章节核对栏编辑。

## 防丢失与隔离

备注只保留在当前窗口。刷新、退出或重启后不保留；需留存时请先导出。没有新增持久化或后台同步。
有备注或待修改项时，“结束核对”必须再次确认；取消保留记录，导出本身不会清空记录。
更换实体、项目或筛选范围，以及缩小范围会排除有备注章节时，拒绝覆盖旧记录，并提示先导出和结束本轮。
同一范围重新打开时保留仍在范围内的记录；打开取消或失败，恢复前一轮完整状态，不再抹掉其进度。
失效返回、过期异步回调和旧结束确认不能清除新一轮备注。特殊 ID（如 `__proto__`）保持普通数据属性。
源码编辑面板打开时，核对导航仍拒绝抢占焦点或丢弃未应用源码。
