## 本阶段功能

在原有「对照版本」内部增加「查看正文差异」。仅用户点击后计算，不在冲突列表挂载或后台刷新时批量比较正文。保留原有两端版本元数据和正文预览。

- 以捕获的本机 / 远端文本投影进行行级比较，显示各自独立行号、「仅本机 / 仅远端 / 相同上下文」和换行类型。颜色之外还有明确文字标识；不把差异方向解释为即将执行的写操作。
- 上一处 / 下一处差异，并在显式导航后将键盘焦点移到当前差异位置。每处差异显示至多两行相同的前后上下文；相邻差异不会误作相同上下文。
- 单处差异较大时每页最多 60 条差异行，明确本处总数、当前范围和页数；尾部差异全部可达，不静默截断。
- 精确保留空格、Tab、CR / LF / CRLF、空行、末尾换行和 Unicode 原文，不先 trim、大小写折叠或 Unicode 归一化。
- 可见文本相同但原始正文不同的情况明确提示格式、链接目标或文档结构仍可能有差异。原始正文完全相同时，也不会据此认定标题、回收站状态等版本字段相同。
- 文件夹、标签、附件、缺失或永久删除的一端不当作空白笔记比较。回收站笔记可只读查看正文，但原有删除警告及确认流程保持不变。

## 性能与完整性边界

复用既有正文投影器。任一投影不完整（含未展示嵌入节点或截断）就不生成行差异，不显示虚假的零差异。超过 512 Ki UTF-16 单元的原始输入不解析用于差异；既有投影上限为 12,000 个码点。

每端最多 2,000 行，去掉共同前后缀后 LCS 矩阵最多 300,000 单元，使用 Uint16Array，避免无界二次分配。超过预算明确拒绝生成差异，保留原有两端预览。模型不可变，不保留用户配置、凭据或额外字段；单次 DOM 最多 60 条差异行加 4 条相同上下文。

这是行级文本辅助，不是字符级语义比较、富文本排版比较或三方自动合并。行号属于文本投影，不等于编辑器排版行号；移动内容可能显示为两端分别存在的行。不能据此自动选择版本。

## 原有安全边界

差异模块没有 API、文件、存储、凭据或冲突写入能力。差异导航不会设置选边、勾选确认或调用处理函数。原有 Review 组件仅增加一个 import 和一个只读子组件，提交、重读、超时、A-B-A 失效锁定及二次确认逻辑不改。

旧对照失效后仍可查看原快照差异，但不能恢复提交资格。显式重新对照（即使同一冲突 ID）会收起旧差异并清空导航位置。多张冲突卡片状态独立。
