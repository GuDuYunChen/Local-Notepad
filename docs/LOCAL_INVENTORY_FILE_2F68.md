## 用户入口和边界

更多 → 设置 → 本地只读盘点 → 查看已导出的统计报告。选择应用导出的UTF-8 JSON v1文件，查看四类数量、精确字节数、共同基线条目和文件声明的生成时间。无需先扫描本机；该入口不调用原生盘点、剪贴板、网络、笔记导入/恢复或同步，不持久化读取结果。明确标为所选文件而非当前工作区，来源/真实性未经验证，不推断来自同一工作区，不将报告时间当作盘点完成时间。

读取前拒绝空文件及超过4KiB的文件；FileReader读取字节、严格UTF-8解码、完整字段/版本/范围/四类顺序及原统计预算校验。重复字段（含转义别名）、多段JSON、错误合计、非法日期、额外字段、格式损坏均整份拒绝；文件中的说明字符串不作为建议或HTML展示。容许一个UTF-8 BOM和合法JSON空白，包括CRLF，不归一数字或私密标识。

每次选择撤销旧请求，立即清除旧统计；选择框取消保留当前结果，支持重新选择同一文件。停止、清除、卸载撤销当前读取并丢弃迟到成功/失败；5秒绝对截止覆盖读取和解码校验，成功和错误均检查截止，不自动重试。使用自有FileReader.abort，不把取消请求当成不配合OS系统调用必定已停止的证明。界面只采用当前请求的结果，A→B→A不能复活旧数据。
