## 用户操作

设置 → 同步中心 → 同步总览 → 离线查看历史文件。成功读入文件后，在查找结果下方增加默认收起的“文件内匹配概览”。

概览使用整份已验证文件的当前筛选交集，不是当前25条分页。分别显示处理结果、对象类型的记录数，以及已知处理/失效时间范围和缺失时间条数。两组总和都等于全文件匹配数；同一对象的多条记录分别统计。失效记录不当成远端或本机选边，未知处理方式不推断。日期只用文件中的处理/失效时间，缺失值不冒充1970年、创建时间或今天。

翻页不改变统计，改变筛选即时更新，但不抢焦点或重置展开状态。输入法候选未确认时，沿用已确认查询并明确说明。更换文件尚在读取、失败或停止时，概览仍属于上一次成功读取的文件；清除筛选不会擦掉这条来源说明。新文件成功读取后，沿用查看器既有重置规则，概览随新记录更新。

文件自身的导出来源和本次FileReader状态分开：例如新文件成功打开，但文件注明导出前读取失败，原文件来源提示保留，不能叫当前数据已同步。概览不改文件声明的导出范围，不证明文件真实性、全工作区历史、当前两端状态或同步成功率。
