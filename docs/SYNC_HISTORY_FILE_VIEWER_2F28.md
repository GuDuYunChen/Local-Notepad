## 使用与隔离

位置：设置 → 同步中心 → 同步总览 → 离线查看历史文件。它是本机“冲突处理记录”的独立相邻面板，默认收起，不与本机历史列表、筛选、概览、日期或导出状态混用。

点击“选择历史 JSON 文件”，可查看本应用已有 v1 和带日期条件的 v2 导出。实际使用浏览器 File 输入与 FileReader 读取所选文件；不上传、不导入、不写数据库、不保存副本或偏好，不执行同步/恢复/选边。文件中的标题和标识可能私密，内容仅保留在当前面板内存，卸载后不恢复。

展示文件名（不显示目录路径）、文件内记录数、文件声明的原已读数/未读页/导出时间/来源状态/筛选边界。来源始终是文件声明，格式检查不是签名校验，不能证明来源真实性或当前工作区/远端状态。原文字查询未写入导出，因此不会假称能重建完整查询。

记录按文件顺序本地分页，每页 25 条，覆盖整个已接受的文件；不发出分页请求。同一对象的不同处理记录不合并。显示当前标题、类型、历史结果、UTC 时间及可展开的标识，缺失时间不伪造日期。标签/名称按文本转义，不运行文件内 HTML 或链接；文件提供的 notices 只验证格式，不作为界面建议显示。

“清除查看结果”只清内存，不删除磁盘文件或工作区。更换文件时保留旧结果直至新文件完整读完且全部验证成功；失败或停止时明确注明仍在显示上次成功读取的文件，不能把旧页当新文件。重新成功读取重置第一页及列表滚动位置。支持重新选择同一文件；取消选择不改变当前结果。

## 文件校验与请求生命周期

最多 4 MiB、2000 条。先检查文件大小，再读取字节并进行严格 UTF-8 解码；不静默替换错误字符，不截断。校验格式版本、字段白名单、数量一致性、唯一记录标识、类型/状态/处理方式及说明、真实 UTC 日期、v2 日期条件和全部记录所属范围。任何一行或声明矛盾则拒绝整个新文件，不显示看似可信的部分结果。未提供查询词，因而不把格式通过视作对原文本条件的验证。

读取等待预算 8 秒，支持停止；更换文件、清除或卸载使旧请求失效，即使不合作的旧读取稍后返回也不得替换新结果。读失败/错误编码/超时给出固定提示，不显示原始路径、异常栈或文件中的指令。

本阶段不修改 App/TextEditor、自动保存、Ctrl+S、引用维护、退出保护、历史输入法与日期应用规则、导出 JSON/反馈、后端、依赖或数据库。
