## 用户可见变化

总览时间区域新增 UTC / 本机时区切换，默认保留原来的 UTC 文本。选择本机时区后显示设备配置的时区名称、当地日期时间以及每个时间点的 GMT 偏移。夏令时重复小时可由偏移区分；保留毫秒，不把最近成功时间变成当前成功保证。

两个时间都保留原始 UTC 的 HTML time datetime 和提示文本。切换不刷新、不执行同步、不修改源时间、不推断相对新鲜程度。选择仅保留在当前挂载的总览实例，父快照更新和帮助往返不重置，另一个总览不跟随。重新打开页面仍默认 UTC，没有添加存储。设备时区在明确点击本机时区时读取，修改设备时区后可再次点击更新。

Intl 不可用、不支持时区、日期边界或格式转换失败时，两项时间一起退回 UTC 并明确提示。缺失记录仍为“尚无记录”，非法输入为“未知”，不会显示 epoch、原始报错或用户私密字符串。支持的扩展年份 UTC 仍原样保留，不强行推断本地纪年。

## 原生平台前的格式兼容修正

首个提交 `4ef63b0` 的新专项在 Node 24 的 Linux / Windows 环境中发现零时差文本差异：CI 返回 `GMT+00:00`，本地 Node 22 返回 `GMT`。同一时间点并未转换错，但严格显示约定不一致，专项因此失败且没有进入后续验收。

现将 Intl 的 GMT / UTC 零偏移统一为 `GMT+00:00`，带 UTC 前缀的非零偏移统一使用 GMT 前缀；日期、毫秒、偏移数值和原始 UTC 不变。新增两个独立 Intl 输出夹具回归用例覆盖多种零偏移标签和 +05:45 前缀转换，不使用放宽时间断言来绕过失败。本地新专项 29/29，连同原有 53 项为 82/82 通过；最终验收以修正后 HEAD 对应的 CI 为准，初始提交的失败记录保留。
