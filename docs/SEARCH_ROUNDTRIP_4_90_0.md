# 4.90.0 — 检索往返与常用检索备份

基于完整 4.80.0 候选源码，整合尚未挂到远程分支的 4.70 / 4.80 功能。
本说明描述源码行为和已执行的本地检查，不能替代正式提交的 CI 状态。

## 检索与编辑往返

从全局检索的“打开笔记”或具体节选定位进入编辑器后，显示“返回检索结果”和“结束往返”。只有原文件打开保护接受了目标，才创建本轮返回信息；取消、打开失败和关闭后迟到的响应都不创建返回位置。

返回只打开检索弹窗，不卸载编辑器、不清空草稿，也不强迫保存。弹窗仍只查询已保存数据，明确提示未保存草稿未参与结果。选择其他笔记仍经过现有保存 / 不保存 / 取消流程。结束往返只移除导航信息，不删除正文、不结束实体核对、不清空已保存常用检索。

返回保存原关键词、目录、来源、排序、置顶和大小写条件，最近 N 天按本次时钟计算。新增只读 anchor_id 参数，后端在当前筛选和排序的结果中按笔记 ID 计算所在页，故保存后标题或修改时间导致重排时可以找到新页，不依赖旧序号或同名标题。目标不再匹配则显示缺失提示，不自动扩大范围；目录删除仍明确失败。返回不携带旧 revision，但随后的普通分页继续核验新的 revision。客户端要求 anchor_id 与 anchor_found 明确回执，不接受旧后端的假成功。

返回信息只驻留当前 App 窗口，包括查询条件、笔记 ID、标题、页码和列表滚动值；不持久化搜索历史或正文，不保留结果节选。刷新或重启不保留此返回导航。

## 常用检索独立备份

全局检索 → 常用检索 → “备份全部常用检索” / “选择常用检索备份”。

备份只包含明确手动保存的名称、关键词和白名单筛选条件及存档元数据；不包含正文、结果、页码和导航标记。最多 40 条、512 KiB。不可读取的条目阻止“完整备份”，不会被悄悄省略。下载按钮仅报告已发起下载，不把点击链接当作磁盘保存成功。

选择 JSON 后预检全部条目，展示新增、本地已有、文件内重复。所有成员均有效且容量足够才允许确认；同名且全部条件相同视为重复，忽略导出时间与原存档 ID。同名但条件不同保留独立条目，不覆盖旧记录。确认前复验本地存储状态，逐条写入后核验原条目未变化。导入途中失败保留成功项，展示实际新增 / 跳过 / 剩余数；重新选择文件预检会跳过成功项。不是整包原子事务，也没有跨窗口分布式锁。

导入创建新的本机 ID，保存时间为本次导入时刻，不保留原历史保存时间作为新的保存时间。不会自动应用或执行导入的搜索，也不改变当前条件。目录标识保持原样，不自动映射到新资料库的同名目录；迁移后应检查目录。文件包含搜索词，使用者应妥善保管。正文数据库、核对存档与常用检索仍是独立备份，不称为整机迁移包。
