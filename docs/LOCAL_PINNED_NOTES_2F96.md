# 2F.96 / 4.229.0 本地置顶笔记整理与安全打开

已验收基线6a74bc0 /4.228.0（PR2评论6207840904）。本模块覆盖原右键置顶与取消、独立侧栏入口、已置顶/全部普通笔记、标题查找和中文输入、排序与分页、选择/最新目标核对/原保存放弃取消后打开、异常停止/持久记录/只读核对/明确结束、关闭重开和安装交付。不是单独增加一个置顶按钮。无云、多端或部署。

## 原缺陷与修补

原FileList.togglePin在写入后调用不存在的loadList，导致已经成功的数据库修改被显示为失败且列表未刷新；原取消置顶没有确认。保留两个真实FileList+原右键菜单负对照。旧FileLogic.Update对仅置顶操作仍写回整个File（包括旧正文及更新时间）；SQLite触发器负对照证明会触碰无关字段。本次仅置顶路径改为写事务内单列更新，保留旧接口的完整File返回及目录支持。混合其它字段的旧接口行为不在本模块重构，不宣称修复所有旧元数据写入并发。

新/local-pins GET一致读取普通存续笔记元数据，不读取正文；/local-pins/{id} GET只读核对，PUT在同一写事务内检查标题、对象类型、确认时置顶状态后只写is_pinned。不改正文、标题、位置、排序值、更新时间、历史、引用或保存回执。旧schema14和679依赖节点不变。

侧栏工作区不包含目录、模板、回收站；原目录置顶仍支持，并可从工作区处理目录置顶的未确认记录。完整列表上限2000篇、2MiB，标题最大16384字节；超限明确拒绝而不是截断成功。每页20条，查找100Unicode字符，字面不解释正则。排序优先置顶，再按最近编辑或标题；置顶不伪造编辑时间。

## 写入与恢复

所有新界面写入前先同步验证本机唯一待核记录已存储，重复点击/其它入口不覆盖未确认记录；存储失败不发送修改。服务器真实回执和身份/目标校验通过且记录清除成功后才显示完成、广播原列表刷新。超时、停止、响应丢失或非法回执都保留记录，不自动重发，不把取消等待当成服务器回滚。关闭/卸载只取消本轮等待与界面更新。

核对只发送GET，展示读取时目标名称/对象类型/置顶状态，不冒充原请求历史回执。目标缺失或暂不可读也可以在尝试核对后明确结束记录，避免死锁；结束和损坏记录清理都需确认并比较原始记录，不清除后来替换的新记录。记录只含目标元数据，不存正文。localStorage不是跨进程事务或断电保证；后端只有当前布尔状态比较，不宣称全局ABA检测或分布式顺序。

选择只展示操作，不立即打开；打开前读取最新正文并核对标题与置顶状态，原useGuardedNoteOpener/App负责保存、放弃、取消。查询、选择与草稿在取消后保留；超时/关闭后的迟到回复不能打开旧目标。导航不绕过原编辑器保护。
