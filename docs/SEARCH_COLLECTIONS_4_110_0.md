# 4.110.0 — 可保存、复查与备份的检索资料集

功能基线：`feature/ui-redesign-v1`，`35d8753041e80f6b3201f8b60c1ad796fd41f38a`（4.100.0）。
沿用现有检索及草稿保护，不修改 master，不增加数据库迁移或第三方依赖。

## 完整使用流程

全局检索 → 结果清单与导出 → 命名 → 保存所选／全部为资料集 → 顶部“本地资料集” → 查看、复查、打开当前笔记或备份 JSON。

保存复用跨页重读、范围版本、数量与身份校验。始终只采集元数据，不受报告导出“附带节选”勾选影响。只有手动保存才写入本机，保留名称、历史检索条件、标题、目录、笔记 ID、修改时间、命中数量、正文指纹和时间；不含正文、节选或编辑器定位 token。

最多 40 份，每份最多 2000 篇、2 MiB。容量不足明确失败，不淘汰旧记录，不截断选择。同名保存是独立资料集，不覆盖历史。损坏记录仍列出并计入容量，不把读取失败当成没有记录。

“本地资料集”独立页签，避免继续向结果列表堆叠面板。每页 8 个历史条目，可搜索两侧标题、目录和 ID，并按变化状态筛选。原检索功能和导出保留。

## 复查不是正文恢复

复查按存档中的固定时间起点和其他原条件重新读取当前全部分页，并复验版本。不重新计算历史“最近 N 天”，不扩大已经删除的目录范围。

按笔记 ID 对齐，互斥统计：本次未变化、正文有变化、元数据变化、不在原检索范围。具体原因可同时包括标题、目录、修改时间、置顶或命中数量变化。

“不在原范围”可能来自正文修改、移动、删除、筛选或解析失败，不作为已删除的证明。“当前范围另有 N 篇不在资料集中”也不等于新建笔记，特别是原来只保存了所选结果时。复查不加入、移除或覆盖历史条目，结果标明检查时间，仅表示该次读取时的状态。

当前匹配超过 2000 篇、查询出错、页号/版本不一致、取消或两分钟截止时，不提供部分复查结论。零匹配也需再验证一次版本。原目录不可用会明确停止，而不是扩大到全库。

打开历史条目时，通过既有 App 文件读取和保存／不保存／取消确认，读取当前笔记，不恢复历史正文或用旧指纹进行字符定位。取消后保留资料集、筛选与页码；成功后清除无关旧检索返回条，重新打开全局检索仍保留资料集视图。本版没有编辑器专用“返回资料集”导航条。

共享打开器对 ID 进行 URL 路径编码，导入的特殊 ID 作为单个路径段传递，仍保留实际身份校验。

## 存储与备份

使用当前应用 localStorage，与常用检索、核对存档和数据库分开。JSON 备份只导出明确选择的一份资料集；导入先做格式和元数据预检，确认时再检查容量，新增独立副本，不自动打开、查询或创建笔记。重复导入也属于明确确认的新副本，不自动去重或覆盖。

备份在浏览器发起下载，不声称已确认落盘。复查与导出前核对本地记录未被更改/删除；关闭、切换条目/页签或进入编辑器确认时，取消失效的准备请求。存储事件、窗口回到前台、手动刷新会重读记录。

跨窗口保存采用独立随机键，删除有旧值校验，但 localStorage 不是数据库事务，容量检查不是跨窗口原子锁。清理应用数据、隐私模式或权限变动可能影响记录，应另存 JSON；正文数据库和核对备份不包含资料集。
