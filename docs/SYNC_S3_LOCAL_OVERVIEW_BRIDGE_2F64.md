## 约束与异常路径

请求进入后先占用单在途槽位再反射参数，重入及并发直接拒绝；没有队列、重试、缓存、重定向或浏览器fetch回退。7.5秒绝对截止覆盖请求及响应，调用方取消会销毁自有请求；结果结束与连接关闭分别处理，ClientRequest真正close前不释放服务槽位。停止等待不等于Go读取已结束；后端自己的单在途槽位和5秒读取截止保持不变。

响应限制4096字节，拒绝重复/冲突长度、压缩、trailer、缺no-store/nosniff或含CORS许可头的响应；检查完整消息、UTF-8和实际长度。JSON拒绝重复解码键和额外字段，所有数量必须是非负安全整数，复核总和、数据库/附件各自硬上限、零项字节数、附件总容量和固定类型顺序。ObservedStable不是原子快照或持续新鲜度；CompleteForPreview必须false，不能提升为同步授权。

IPC注册器复用原窗口/主frame/页面身份与导航取消策略；转发前后二次确认当前租约，重新生成递归冻结的白名单对象，不透传服务返回的私有字段、getter或异常文本。构建本模块不启用读取行为，公开意图头不是认证。未来宿主接入必须提供本地进程访问控制和真实资源授权，不能由这些测试代替。
