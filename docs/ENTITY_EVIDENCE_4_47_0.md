# 4.47.0 — 正文证据回看

基线：`feature/ui-redesign-v1`，`d22d5bbbc7698ee01aab099948ec38d10bad3646`（4.46.1）。
上一版 CI 运行 `35837283108` 的 renderer-build、windows-package 均已成功，包括编辑器回归、后端 HTTP 冒烟和打包后 Windows 应用验证。

## 使用入口

项目的实体智能分析区选择人物、地点等实体后，在热力图下方使用“正文证据回看”。不新增顶层导航，不替换编辑器或主题。

- 展示原名、确认别名的命中文字及上下文；高亮是普通 React 文本，不执行正文中的 HTML。
- WikiLink 独立展示真实链接标签及目标小节，不将链接标题伪装成正文引文。
- 支持按证据来源、所在卷、章节名／卷名／命中别名组合筛选；搜索不是全文检索。
- 每页 6 个章节，可浏览全部证据章节，不再只截取前 10 章；保留原章节序号。
- 混合来源章节可以出现在多个来源筛选中，结果总数按当前来源与筛选范围计算。
- “打开章节”调用既有文件打开功能。此版不会将光标精确定位到高亮处。
- 切换项目或实体时重置筛选与分页；不存在的实体、缺少正文、无匹配结果均有空状态。

## 准确性与性能边界

识别仍使用 4.46.1 的统一词项扫描器和最长匹配规则，未修改置信度、关系接受逻辑或正文。
采样为显式启用：默认扫描返回值和统计保持不变。证据页面只为当前页生成节选，每章最多展示每种来源 3 个样例，并明确提示其余提及数；样例截断不会截断统计。
上下文不跨段拼接，截取保留完整 Unicode 字符。节选文本经过 NFC／编辑格式归一化，其位置不能当作原文编辑器选区偏移。
共现只是人工复核线索，不自动建立关系。
