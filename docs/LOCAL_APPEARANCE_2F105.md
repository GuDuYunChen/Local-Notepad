## 用户操作与数据边界

内置原生、松林绿、海洋蓝、梅子紫四个方案只读。复制后可编辑名称以及浅／深色模式的六位十六进制强调色。最多 12 个自定义方案；名称 1～32 个 Unicode 字符，拒绝控制字符和重复名称。为按钮文字／链接限定颜色与对应两种背景的对比度至少 4.5:1；该检查不代表整个产品的无障碍认证。

编辑和预览不写配置。预览通过独立会话只改变九个界面强调色变量；取消预览、关闭或父路由卸载都会恢复已应用方案，并保留原浅／深色选择。用户在正文中指定的颜色和内容不被改写。默认方案移除覆盖并恢复原有 CSS 值与优先级，不通过反色滤镜实现。

“应用并保存”严格校验完整配置，检查读取时的旧值，写入独立的 `localNotepad.appearance.v1`，并读回一致后才显示成功。每次写入有新修订标识。不会发出笔记保存请求、不读写笔记数据库、草稿缓存、保存回执、CAS、退出队列或附件。原 ThemeToggle 的浅／深色保存逻辑原样保留。

浏览器 localStorage 不提供跨进程原子 CAS。本模块拒绝已经观察到的外部写入，并在收到对应 localStorage 事件后取消预览、保留编辑、阻止直接应用，要求用户明确重新载入。不声称能阻止所有极短时间的双窗口并发覆盖。无关 sessionStorage 事件不改变预览。

## 文件交换

导出当前方案为 `local-notepad-theme.json`，只包含固定格式、版本、名称及两个颜色值，不含本地方案 ID、笔记、文件路径或账户：

```json
{
  "format": "local-notepad-appearance",
  "version": 1,
  "scheme": {
    "name": "我的绿色",
    "lightAccent": "#176b4a",
    "darkAccent": "#80d6ad"
  }
}
```

导入只接收不超过 16 KiB 的非空 JSON，逐层拒绝未知字段、原型字段、任意 CSS、URL、不支持版本及不可读颜色。同名导入生成新 ID 和可区分的名称，不覆盖现有方案，不立即应用。文件读取有 10 秒截止和取消；切换方案、重新载入、关闭后，迟到读取不能改动新的会话。导出只报告“已请求下载”，不冒称磁盘写入完成或用户已选择路径。

## 异常闭环

- 存储不可读：使用临时默认显示，不覆盖未知原值，重新载入成功后才能应用。
- 损坏／不兼容配置：保留原始字节，必须明确确认修复或重置后才能替换；仅影响主题配置。
- 配额／写入失败：保留当前编辑，显示错误，可以重试或取消；不将预览显示当作保存成功。
- 写后读回错误或不一致：不显示成功，不发送应用成功事件，要求重新载入确认实际状态。
- 删除／重置／放弃未应用编辑：明确确认；确认删除和重置仍为待应用状态。
- 键盘：对话框焦点循环、关闭恢复入口焦点；输入法组合中的 Escape 不误关闭，Ctrl+S 不传给底层笔记编辑器。

操作错误、外部配置变化、损坏配置修复及成功回执位于独立的固定反馈区，不随方案表单滚动离开操作按钮。最小窗口保留可滚动表单与可见操作栏；取消预览立即更正状态文案，不继续显示“正在预览”。真实 Windows 验收还须检查反馈的可见矩形与遮挡，不能以 DOM 中存在文字代替用户看得到。
