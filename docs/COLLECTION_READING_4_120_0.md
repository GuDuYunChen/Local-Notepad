# 4.120.0 — 资料集连续阅读与完整复查报告

基线：`feature/ui-redesign-v1`，`757cbef4b0f92bf371729484123971f4ee4a5408`（4.110.0）。保留既有检索、资料集存储和 Windows 安装模板修复；不修改 master、数据库结构或正文。

## 一次走完的操作流程

全局检索 → 本地资料集 → 选择资料集并筛选条目 → 打开当前笔记 → 上一资料／下一资料 → 返回资料集。

阅读队列包含进入时完整筛选范围，不只包含当前页的 8 条。顺序取自该历史资料集及当时的筛选，打开时通过既有文件读取器读取当前正文；不恢复历史正文、不进行字符级定位。上一／下一不循环；取消、保存未完成或笔记不可用不推进位置、不自动跳过条目。

“返回资料集”恢复原资料集、查询、变化状态和对应页，按笔记 ID 聚焦原条目。返回只打开清单，不保存、不丢弃编辑器草稿；再次切换笔记仍经保存／不保存／取消确认。“结束资料集阅读”只移除导航，不删除清单或草稿。

返回含复查筛选的队列时，保留进入时的复查快照并明确提示不是实时状态；不会将编辑后的正文误标成已经重新检查。点击“检查当前变化”可更新检查结果，复查报告导出则始终重新检查。

阅读上下文仅在窗口内存中存在，关闭应用后不恢复。所含历史记录原始字符串只用于来源旧值校验，不写进复查报告。来源记录被更改、删除或不可读取时，后续切换失效，返回显示错误，绝不重建记录或自动切换其他资料集。窗口获得焦点与存储通知时同步检查；每次打开前及保存确认后还会检查一次，不依赖通知一定送达。

## 草稿确认的修复

原有文件打开器新增可取消信号和来源有效性条件，未传这些参数的旧入口保持原行为。取消会解除挂起的读取／确认并移除监听器，迟到结果不能选择旧目标。

发现并修复：保存确认显示期间来源失效，原来的“不保存”会先清理草稿再发现不能跳转。现在在保存或丢弃前先检查挂起目标；来源失效直接取消跳转，草稿及缓存保留。用户已经明确完成的保存不做逆向回滚。

## 重新复查并导出完整报告

资料集页展开“复查报告与阅读说明”，选择“重新复查并导出 Markdown／JSON”。每次重新读取原固定检索条件的当前全部分页，沿用数量、身份、版本和最终复验；校验来源记录仍未变化后才发起下载。

报告包含全部历史条目、历史与检查时的元数据、互斥变化状态与原因、当前范围额外匹配、两侧范围版本、条件及检查时间。导出不受当前页、查询或变化状态筛选限制，不更新历史记录，也不附带正文、命中节选、存储键、原始记录字符串或导航队列。

“不在原范围”不证明已删除；额外匹配不代表新建。正文指纹变化可以来自格式或序列化变化，不代表语义差异。JSON 使用独立的复查报告格式，不能作为资料集备份导入。Markdown 源字段按文本转义，不能变成活动 HTML、链接或代码围栏。

来源变化、传输失败、取消、原目录不可用、读取不一致、两分钟截止或报告超过 8 MiB 均不生成部分文件；每侧最多 2,000 篇，仍受原资料集大小和完整复查限制。下载使用现有 Blob 流程，“已发起下载”不声称已核实系统写盘。检查时间只表示最后读取时的数据，不承诺导出后资料库不再变化。
