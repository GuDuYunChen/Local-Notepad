# 4.130.0 — 资料集阅读进度与批注

基线：`feature/ui-redesign-v1`，`0ce4d20be3b2bae2ea8fae8bc19f0749629bafeb`（4.120.0）。不修改 master、数据库结构或正文；不新增依赖。

## 使用流程

全局检索 → 本地资料集 → 阅读进度与批注。可以按未读、已读、待复看筛选，搜索标题、笔记 ID 或已存批注，每页八篇；选择条目编辑批注，不必打开正文。

从资料集打开正文后，连续阅读栏也提供同一份批注编辑器。“保存批注与进度”明确写入本篇人工状态、批注和笔记级书签；“记住当前阅读位置”只保存书签。打开笔记、翻页、自动保存正文或运行资料集复查，都不会自动标记已读。

“下一未读资料”沿进入时的完整阅读队列查找，跳过已读，保留待复看，最多循环一次且不把当前篇当成下一篇；找不到时停用。取消、未保存确认或目标打不开仍沿用原有保护，不推进位置或自动跳过失败目标。

重开资料集后可以“从上次位置继续（全部条目）”。它使用全部历史条目而不是旧复查结果，不恢复上次筛选或精确光标位置；打开当前正文仍经过保存／不保存／取消确认。普通“返回资料集”继续保留 4.120 原有的返回范围逻辑。

## 保存与批注草稿

已存阅读记录使用独立 localStorage 键，绑定资料集 ID 和完整历史检索报告的 SHA-256。人工标记不是正文正确性、语义或最新版本的证明；正文改变不会自动重置标记，请自行复看。历史资料集内容不因保存阅读记录而改变。

批注最多 2000 个 UTF-16 代码单元（界面计数），记录／备份最多 1 MiB，超限拒绝，绝不截断。保存前同时验证备份大小，保证正常保存的记录能够完整导出。

未存批注只进入当前窗口草稿缓存，切换笔记或重开面板不会静默抹掉；重新读取不会覆盖正在编辑的草稿。缓存最多 64 份，超限拒绝新草稿而不淘汰旧草稿。普通关闭尝试注册 beforeunload 提醒，但不保证系统强退、崩溃或断电恢复，请显式保存或导出草稿 TXT。舍弃当前草稿需要再次确认。

同源窗口通过 Web Locks 串行保存，同时校验来源记录和旧值。陈旧保存／导入拒绝覆盖新记录，批注草稿保留。获取锁五秒超时、锁不可用／被拒绝、存储空间不足均明确失败，不回退到无锁覆盖。不同来源页面、外部篡改或历史版本代码不在同一协作锁契约内。

## 备份与导入

“备份阅读记录 JSON”覆盖全部已存人工标记、批注和书签，不受显示页或筛选限制，不含正文、命中节选、未存草稿或来源原始字符串。

迁移时先单独备份／导入历史资料集，再导入阅读记录。即使新资料集 ID 不同，只要历史检索报告完全一致，也能预检匹配。不同历史结果（即使同名）拒绝导入。

预检不写入；确认替换前再次核对原资料集和当前已存阅读记录。导入只替换这一份阅读记录，不创建正文，不覆盖历史清单，不删除窗口中的批注草稿。需保留当前状态时先备份。

资料集、阅读记录、核对存档和数据库备份仍独立。删除资料集不会自动删除其阅读记录；删除前应分别导出两份 JSON，当前版本不提供孤立阅读记录管理页。清理浏览器／应用站点数据会移除本地记录。
