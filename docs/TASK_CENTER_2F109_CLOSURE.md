# 2F.109 同模块收尾：原编辑器复选框与文字间距

Windows #77 的机器检查通过，但 `task109-editor-saved.png` 显示复选标记遮挡任务开头的文字，不能据此接受该安装包。原图、原报告和来源身份保留。

根因：`editor-document.css` 中 `.editor-input .editor-list-item` 的通用重置优先于 `Editor.css` 中单类清单规则，将勾选/未勾选行的预留间距变成0.12em。只针对原编辑器清单类增加更明确的28px左侧间距，容纳固定16px标记及支持字体尺寸下的空隙；普通列表和编辑器外布局保持，正文、勾选和保存逻辑不改。

本地真实样式级联测试在旧实现上4项清单反例失败、2项普通/外部对照通过；修补后6项通过。它不是浏览器布局证明。Windows新增验收还须用真实文本Range和伪元素矩形检查勾选前后、正常/最小窗口的首行不重叠，再查看当前安装包截图。

首次级联测试夹具使用Vitest的CSS导入替身和浏览器URL读取失败，已改为读取实际CSS；初次错误不能当作产品负例。第二次夹具错误预期未转换的em字符串，改为核对实际计算值；只有最后“4失败/2对照通过”作为确定性旧实现反例。这些原始记录保留，不修改产品来迁就测试。
