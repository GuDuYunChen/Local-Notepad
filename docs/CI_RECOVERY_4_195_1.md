## 实际改动
提交 npm 生成的完整 package-lock v3，包含 Windows/Linux 原生可选构建包和每个 tarball 的完整性值。直接依赖声明不变，首次锁定会固定此次解析的传递依赖；它不是先前保留 node_modules 的隐藏锁，也不宣称与旧运行时所有传递版本相同。

九条 CI 工作流、十个安装步骤改为：无依赖锁预检 → npm ci → 确认 manifest/lock 没有被安装改写。没有失败时回退 npm install、跳过测试或关闭完整性校验。开发启动命令也改用已安装且被锁定的 Electron，不再额外通过 npx electron@31 解析版本。

新增无第三方依赖的校验脚本及 24 条回归：版本/声明不匹配、缺包、无效完整性、非固定版本、非官方 tarball 来源、缺 Windows/Linux 可选包均失败；缺锁 CLI 返回非零且不重新生成。脚本结构通过不是 npm 安装成功，下载字节及依赖图仍由 npm ci 验证。SaveRecovery 原始产物另外记录精确 lock SHA256。

新增开发接续文档，区分源码进度、测试进度和交付进度，避免中断后从过期阶段重新开始。临时候选工作流仅生成锁和未引用的 Git blob；最终树将其移除，不保留新增的工作流写权限。
