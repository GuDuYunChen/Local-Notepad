非 JSX 补充核对涉及两个组件、九个控件源位置：八处普通控件使用共享组件，一处 checkbox 保留原生语义。`S3ReadInspectionPanel` 可通过实际设置入口到达；`S3PreviewPanel` 的两个按钮统一构造方式，但没有因此新增入口或业务。检查已有 S3/WebDAV 表单不需要用户真实凭据，不执行真实同步或远端探测。

## 三张截图与源码复核

### UIR-004：WebDAV密码输入存在重复焦点层（待修复）

截图：原输入边框之外还有宽外轮廓，焦点视觉重复。

源码：SyncCenterPanel.jsx的密码入口仍是原生input；SyncCenterPanel.css的`.sync-provider-card input:focus`修改边框并添加box-shadow，dark-theme.css又通过全局`:focus-visible`添加带`!important`的outline。两种焦点机制会同时参与同一输入的样式。截图没有证明DOM重复嵌套，也没有给出完整计算样式，不能把它描述成已经测量出的盒模型问题。

修复验收：组件库Password/Input只保留一套明确焦点反馈；正常、键盘聚焦、错误和禁用状态分别检查；清理冲突的旧覆盖规则，不得全局移除键盘焦点环。保留密码不回填、自动填充策略和原保存/清除语义。

### UIR-005：资料集使用原生select而非统一组件库下拉（待修复）

截图：下拉展开后的选项高度、背景和外框风格不协调，焦点外轮廓突出。

源码：SearchCollectionsPanel.jsx的`已保存资料集`和`资料集变化筛选`均为原生select，按钮也由该页面直接绘制。CollectionPackageTransfer.jsx承载截图下方的便携备份入口。不能只美化select外框，就宣称组件库弹出层已接入。

修复验收：统一Select的触发器、弹出面板、选项、选中/悬停/禁用/空状态；检查长名称省略与完整名称可访问、弹层定位和宽度、滚动、键盘选择、Escape关闭及焦点返回。选择/删除/导入/刷新沿用原model与保存保护，不创建第二份业务状态。

### UIR-006：置顶笔记筛选栏混用控件尺寸（待修复）

截图：查找输入、显示范围、排序和清除按钮不等高、行内视觉不齐。

源码：PinnedNotesPanel.jsx使用原生input/select，清除按钮使用`btn small`；PinnedNotesPanel.css给输入和select单独定义padding、字体、边框、圆角，`.pinned-tools`仅做底对齐。底对齐不能抵消同排控件高度不同。

修复验收：同一筛选行使用组件库同一size和统一字段标签布局，清除操作不混入紧凑尺寸；窄窗口按字段组换行而非挤压；保留中文输入法、查找、范围、排序、清除后焦点和加载禁用行为。

### UIR-007：此前19页面范围遗漏实际可见入口（开放）

上述SyncCenterPanel、SearchCollectionsPanel、PinnedNotesPanel不在原19页面候选范围。此次应按全仓清单逐入口归类，而非把19页、297处旧候选统计当成全应用完成。

2. 设置与本地工作台：主题、快捷键、标签、文件夹、统计、附件、待办、回收站、重复检查、比较、历史、导入/导出、备份、命名与确认弹窗。
3. 检索资料集与研究界面：资料集选择、阅读/研究、批处理、报告、项目/关系等所有现存表单和操作区。
4. 现存同步设置及诊断：仅统一已存在界面，不执行用户真实同步、不增加远端业务。
5. 编辑器：工具栏、查找、链接、表格、图片/附件、公式和其它节点属性控件。编辑器正文、代码输入、拖拽句柄、隐藏文件选择不得盲目当作普通表单替换。
6. 少量历史UI库引用与未引用组件：确认入口和依赖后再决定复用或删除，不能仅凭文件存在判定集成完成。

## 统一整改约束

- 使用项目确定的成熟UI组件及官方组合方式；必要适配只保留现有业务事件、ref和语义，不重写一套通用按钮/输入/下拉的外观与行为。
- 统一通过主题/组件token配置尺寸、颜色、圆角、密度和焦点；普通表单同排同size，紧凑编辑器工具栏保持自己的密度，不全局粗暴改`.btn`/`.input`。
- 按钮区分主操作、次操作、文字操作、危险操作和图标操作；有名称、禁用反馈和键盘焦点，不能统一成满屏边框按钮。
- 普通卡片不叠装饰阴影；浮层只保留必要层级。语义性的选中、焦点、错误和差异标记不得当装饰删除。
- 替换控件时同步移除/收窄旧CSS覆盖，特别是全局`:is(input,select,textarea)`与`!important`规则；不得靠继续堆高优先级修复组件库内部样式。
- 保留原接口、数据、保存/草稿/退出、权限、取消、超时、重试和中文输入法；适配Select的值事件、ref/focus、原生fieldset语义和表单提交，不能只批量改标签。
- 用当前候选真实窗口检查浅/深色、最小704×455客户端、常规和大窗口、长文案、弹层位置、Tab/Enter/Escape、错误/禁用/加载等状态。自动静态清单不是视觉验收替代品。
