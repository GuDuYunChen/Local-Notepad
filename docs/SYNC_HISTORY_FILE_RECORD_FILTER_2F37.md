## 新交互

离线历史文件每条记录增加“只看此条记录”。它使用已验证记录的完整记录标识，对整份文件做精确记录限定，再与现有精确对象限定、文字、对象类型、处理结果、UTC日期、排序和分页组合。

记录标识与对象标识一样按不透明身份处理：不做大小写折叠、全半角转换、Unicode归一化、trim或子串比较。启用后显示完整记录标识和“取消记录限定”；单独取消只移除记录限定，保留对象、文字、类型、结果、日期及排序。完整“清除文件内筛选”仍一次清除所有文件内筛选。重复点击同一记录为无操作并保持按钮焦点；失败/取消/停止文件替换保留旧限定，成功读取新文件、清除查看结果或重挂载会清除。

## 边界与验收

只筛选当前内存中已验证的文件投影；不新增FileReader、HTTP、下载、Clipboard、存储、文件写入或原文件修改，不接触正文自动保存/Ctrl+S、保存回执/队列、引用维护、退出保护、Electron产品代码、后端、依赖或数据库。

新增独立Node契约、React组件测试，并在既有Windows三布局21帧及对象限定证据之后追加记录限定、与文字交集为零、单独取消和全部清除四项真实DOM观察。旧报告没有这些记录限定观察，不能替代新HEAD验收。当前HEAD仍须完成八条PR流程、push完整UI/Windows打包、独立桌面与原始产物核验；通过前不进入2F.38。
