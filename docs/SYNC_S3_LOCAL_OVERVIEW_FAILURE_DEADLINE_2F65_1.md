## 修补行为

不会刷新截止时间、重试、排队、增加网络调用或浏览器回退。原生 Promise 未结算时仍保留在途槽位；停止等待仍不代表底层 I/O 已结束。统计为 null 的错误结果不透传私密异常。未修改 React hook、Go、Electron 桥、保存/草稿/退出、schema14、原有测试和工作流。
