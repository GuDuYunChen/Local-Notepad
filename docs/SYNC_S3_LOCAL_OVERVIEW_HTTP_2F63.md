## 交付能力

新增NewS3LocalOverviewHandler。可信宿主一次绑定已授权的借入数据库、附件根能力和显式预算；构造不读数据。请求只表示读取意图，不能传路径、数据库、凭据、pin、记录或预算，也不能扩大绑定范围。

契约为POST /api/sync/s3/local-overview，X-Notepad-Read-Only: s3-local-overview，application/json，正文仅含readOnly:true且最多64字节。允许JSON空白和等价的单个转义键；重复键、大小写别名、未知字段、尾随内容、编码正文或trailer全部拒绝。复用原loopback/browser guard，不开放CORS。公开意图头不是认证，统计仍泄露粗粒度本地活动，不能作为公共遥测。

成功只返回原固定概览：四类记录数量、规范JSON字节、附件总字节和共同基线数量。沿用原D1/A1/D2/A2读取及清理，并复核字段、总和、子预算和枚举。无正文、附件名称、路径、hash、远端身份或凭据。CompleteForPreview始终false；ObservedStable不是跨资源原子快照，统计不是远端计划、同步授权或新鲜度证明。

每个绑定实例仅一个在途请求，无排队、缓存、重试或自动任务；复制实例仍共用槽位。取消不提前释放仍在执行的读取。获准的正文在扫描前关闭，关闭失败不开始读取；借入db/root由宿主管理，处理器不关闭。一个5秒或更早调用方截止覆盖正文、读取与返回前检查，不刷新子截止，不另起游离goroutine。它不保证中断不配合的系统调用，宿主必须设置入站ReadTimeout并且不能提前解析正文。

错误只含固定code/message和null数据：400请求无效、403非原生来源、405方法错误、408取消、413超限、415格式拒绝、422读取或结果无效、429忙、503未初始化、504超时。响应no-store/nosniff，清除所有Access-Control-Allow-*头；内部格式化不泄露借入能力。
