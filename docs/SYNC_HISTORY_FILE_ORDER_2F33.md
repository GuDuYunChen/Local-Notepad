## 新功能

位置：设置 → 同步中心 → 同步总览 → 离线查看历史文件。全匹配概览与记录列表之间新增“文件内显示顺序”：文件原顺序、处理或失效时间由新到旧/由旧到新、建立时间由新到旧/由旧到新。

处理顺序：全文件文字/类型/处理结果/UTC日期筛选 → 全匹配集合稳定排序 → 每页25条。最多2000条对应80页。按时间排序时，缺失或无法按现有时间显示规则解释的记录置于末尾；时间相同按文件原位置排列。文件原顺序不移动任何记录。不猜日期、不按标识或本机语言改变并列顺序，不原地排序源数组。

切换排序回到第一页并滚到列表页首，清除旧跳页草稿/错误；同一排序值和普通父级重渲染保留上下文。选择框DOM及焦点保留，文字筛选、未确认输入法草稿、已应用日期及未应用日期草稿不因排序被重置。真实输入法失焦仍遵循原查看器确认规则。

排序与筛选独立：清除筛选保留排序，切回“文件原顺序”恢复原始排列。成功替换/重新读取文件、清除查看结果时恢复默认排序；失败替换、取消选择、停止读取及迟到旧响应不能覆盖旧文件排序、页码或错误。零匹配仍可选排序，但不生成1/0页或伪记录。

只改变当前窗口显示；不增加FileReader重读、HTTP、下载、存储写入或修改原文件。全匹配概览、原文件声明及上方本机历史保持不变。正文自动保存、Ctrl+S、引用维护、保存队列/回执、退出保护、Electron产品源码、后端、依赖和数据库未修改。
