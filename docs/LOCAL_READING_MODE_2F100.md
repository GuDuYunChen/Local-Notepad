# 2F.100 / 4.233.0 — 本地阅读与编辑模式完整闭环

## 阶段目标
在现有 Lexical 编辑器中提供可切换的阅读模式与编辑模式，先完成本地体验；不开发云、多端同步、更新或推送。

## 实施范围
- 编辑器通过 Lexical 的 `setEditable` 切换，不用 CSS 伪装只读。
- 阅读模式保留文本选择、只读查找、Wiki/普通链接和目录导航；编辑工具栏、写入插件与自动聚焦仅在编辑态启用。
- 阅读态独立调整正文留白、宽度、段落和标题间距，窄屏收紧边距；继续使用已有字体、行距、正文宽度偏好。
- 模式偏好保存在本地；读取损坏或不可用时回退到编辑态，写入失败提示用户但不阻断本次会话。
- 切换模式不卸载 TextEditor、不重载正文、不触发保存或丢弃决定。未保存正文在阅读态明确提示仍被保留；自动保存、冲突处理、退出保护与重试逻辑不另建一套。
- 空白笔记在阅读态使用只读空态文案。

## 历史问题防复发
沿用 `docs/KNOWN_ISSUES.md` 的46条历史问题及12类助手执行事故。重点保护 SAVE-04、SAVE-09、SAVE-14、SAVE-16、SAVE-17、SAVE-18、SAVE-19：未知保存结果不当作回滚、迟到采用不覆盖草稿、存储失败不遮住内存新内容、卸载后不继续发PUT、读取必须有截止、A→B→A按顺序保存、队尾未完成不得显示已保存。阅读态不建立第二套草稿、保存或历史机制。

新增测试覆盖模式偏好默认值/损坏值、持久化与存储失败，以及TextEditor真实切换readOnly和正文身份不变。代码提交后的完整 React/Go/Electron、浏览器、Windows原生与安装生命周期验证以当前HEAD原始结果为准；未运行检查标记NOT_RUN，不以代码已写入代替通过。
