# 2F.98 / 4.231.0 本地 Wiki 引用预览与安全导航

已验收基线7b93775 /4.230.1、PR2评论6221880635。沿用原feature/knowledge-os-phase2 /Draft PR2。历史46产品/环境与12助手执行类别分别保留；本阶段不扩展云端、多端或远程同步。

## 完整操作链路

原Wiki链接插入/保存 → 悬停或键盘聚焦读取预览 → 点击/回车激活 → 最新目标身份及章节核对 → 原保存/放弃/取消决定 → 打开完整笔记或精确章节 → 失败提示/明确重试/停止/仅打开正文 → 关闭提示并重新进入。插入及正文保存使用原Lexical和保存流程；本模块不创建替代编辑器、写正文接口或引用修复事务。

旧App的Wiki事件直接启动无界GET，再调用发起时的handleSelectFile闭包；期间输入草稿或切走可让旧回调继续选错笔记。现在使用原useGuardedNoteOpener与独立来源代次、同步互斥、AbortSignal和10秒读取截止；只有最新有效来源可到达当前保存决定。用户保存决定本身不套网络超时。一次停止/关闭不自动重发，重复激活同一在途目标共用一个请求。记录最近引用只发生在确认打开之后，不影响正文。

旧预览保存全局缓存且请求不取消、无界等待，回收站目标与错误结构未校验；可选反链计数错误被变成空数组。新预览按每次可见生命周期重新核对，关闭/目标变化/卸载取消等待，不跨目标缓存正文；严格拒绝错误身份、目录、模板、回收站、无效正文和超限结果。反链计数失败显示不可用，不显示假零。重试/刷新预览不激活链接。IME确认键不作为打开指令。

## 章节与数据边界

读取正文上限2MiB、结构深度64、最多50000节点；目标标识最多512 UTF-8字节，单段URL编码；标题最多16384字节；章节路径最多32段，每段最多512 Unicode字符，拒绝非法类型及控制字符，不强制字符串化或截断。正文超限不是空正文成功，失败信息不泄露原始服务错误。

其他笔记依据读取时最新已保存正文检查精确章节路径；当前笔记根据当前编辑草稿解析，新增未保存章节无需为跳转额外保存。重复或缺失路径明确拒绝，不选择第一项、不猜测重命名。用户可明确选择“仅打开笔记正文”，不擅自降级。当前草稿章节在待决期间变化会使旧定位失效。实际章节定位继续由原DocumentOutline执行；发送事件增加文档ID和导航代次，帧延迟不能落到另一个文档。

这不是跨客户端原子读取锁：目标仍可能在读取后由其他进程改变，定位器继续核对当前编辑器。存储历史不是持久审计或备份。原数据库schema14、679依赖节点、正文/回执/草稿/退出策略不改。
