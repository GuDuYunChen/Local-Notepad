## 使用与边界

设置 → 同步中心 → 同步总览 → 冲突处理记录 → 筛选已读取记录 → 按处理日期筛选（UTC）。

提供全部处理日期、指定日期范围、仅时间缺失三种方式。范围可只填起始或结束日期，不能两边都空；严格校验真实日期和先后顺序。起始日从 UTC 00:00:00 开始，结束日包括 UTC 23:59:59。不读取设备时区、不使用移动的“今天”、不以创建时间补充处理时间。范围排除时间缺失记录；专用缺失方式只匹配原有零值标记。

日期是独立的筛选草案。点击“应用日期筛选”或在日期框按 Enter 后才生效，不把半输入日期立即变成空结果。输入未完成、越界、不存在、范围颠倒时明确提示，原已应用条件、列表、概览与导出保持不变。草案未应用时明确说明列表、概览和导出仍使用当前已应用条件；没有引入新的笔记保存步骤。

日期输入保持浏览器原生编辑缓冲，不用受控重渲染抹掉尚未完成的年月日；应用前同时核对浏览器 validity 与严格日历日期解析。Ctrl+S 不作为“应用日期筛选”，也不被此组件拦截。

日期与文字、对象类型、当时处理结果取交集，保留服务器顺序。手动读取更早页后重用相同条件；未读页不自动获取。刷新失败或停止读取后，旧快照标记保持明确。应用相同日期不重复清空有效导出提示；日期 A→B→A 必须丢弃旧提示，不能冒充又下载了一次。

“清除本地筛选”同时清除已应用日期与未应用草案，包括原已应用条件本来就是“全部”的情况；仍不改变服务器记录类型，不发请求，键盘焦点仍回到查找文字。

## 导出兼容

未应用日期限制（全部处理日期）时，原 JSON v1 字段与字节生成规则保持不变。使用指定范围或仅时间缺失时输出 JSON v2，并增加唯一的白名单 filters.completedDateUTC：{mode, from, to}，以免下游把日期筛选后的子集误认为无日期限制的结果。空端点表示不限制该侧；所有日期为 UTC，结束日期包含当日。

两个版本都只导出当前显示的已读取记录；不导出未应用草案、正文、查找词、分页游标或凭据。仍保留旧数据来源、已读取/导出数量、未读页、2000 条/4 MiB 上限和仅确认“已请求下载”的语义。本阶段没有导入功能或数据库格式改变。
