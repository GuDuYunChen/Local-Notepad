## 新功能

在现有冲突队列增加「关注项」筛选，可以与名称 / 编号搜索、对象类型同时使用。支持删除或待核实、含永久删除、含回收站、版本缺失、状态待核实。保持服务端顺序和每页十条分页，筛选后仍可到达末页。

列表在打开正文对照之前直接显示两端提示，例如「本机：在回收站」「远端：永久删除」「远端：版本快照缺失（不等于删除）」。无明确删除声明的普通记录不标为“安全”；不能把版本未提供推断为已经删除，也不根据标题或哈希猜测删除风险。格式 / 版本 / 身份 / 状态等必要元数据不合法时标为待核实，布尔值不进行隐式类型转换。

分类可以重叠：一个冲突可以本机在回收站而远端已永久删除。每种分类按冲突计数而非按两端计数；“删除或待核实”是去重总数。筛选计数来自完整的最近读取列表，不随着搜索文字改变。界面说明各类数量不可直接相加，未标记不表示没有风险。

## 不变的确认边界

新提示只描述捕获的快照，不表示下一步会执行删除，也不会替用户选择本机或远端版本。新的关注项筛选和清空筛选复用原浏览入口，收起旧对照并清除旧确认；筛选 A → B → A 不恢复授权。普通同内容刷新仍保留已有有效对照。

提交中的同步单飞锁同样禁止关注项变化，覆盖同一事件轮次先确认后筛选的竞态；状态读取失败或未保存配置时可以查看筛选标签，但不能恢复处理权限。原 SyncConflictReview、实际处理回调、后端版本 / 结构 / 事务检查、预演停止等待及编辑器退出流程不变。

索引只增加不可变的固定风险标签，不读取或复制笔记正文，不保存密码、哈希、路径或任意额外对象。没有新增网络接口、持久化、导出、批量处理、自动选边或实际删除操作。
