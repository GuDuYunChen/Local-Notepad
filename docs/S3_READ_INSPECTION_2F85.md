## 使用闭环

更多 → 设置 → 云端只读检查 → 打开 → 输入根地址、桶、区域、前缀和对象键、本次凭据、读取限额 → 确认只读 → 开始检查。也支持Ctrl/Command+Enter；中文组合输入不会误触发。输入错误定位首个字段，零对象请求。

目标是一个S3兼容存储对象的完整、有界只读检查，不是完整同步、对象列表或文件管理。使用现有useS3ReadProbe、binding/session、生产preload/main及Go读取器；不增加浏览器直连、代理API或备用请求路径。根地址仅HTTPS或明确回环HTTP，原Unicode、空格、字面百分号和前缀不被前端规范化；最多1MiB，超限不采用部分数据。

显示本次接受字节与对象HTTP状态，零字节成功同样显示。结果不能证明凭据普遍有效、对象必然存在/不存在、列举/写入权限或同步完成。401/403、404、重定向、5xx、超限、正文/编码异常、传输/超时、非法原生返回和无原生环境均给出固定说明与手动恢复路径。

停止采用不等于终止底层I/O；原生Promise未结束时保留槽位、拒绝重入、不排队或自动重试。旧调用结束后由用户重新检查。修改输入立即失效，A→B→A不复活旧结果；迟到成功/失败不能写入新生命周期。清空、关闭及离开设置移除面板输入；关闭后焦点回到已经启用的入口。凭据不写配置、日志、备份或Web存储；不承诺安全擦除运行时内存。
